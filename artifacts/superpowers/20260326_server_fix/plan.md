# サーバー間ホームディレクトリパス伝搬の復旧計画

[システム側 implementation_plan.md と同一内容をここに保持します]

## 概要
macOS においてバックエンドサーバーが特権昇格（root実行）された際、一般ユーザーのホームディレクトリ（`~/.mycute/`）を見失い、設定やデータベースの不整合によりサーバーが起動・連携できない問題を解決します。
以前存在していた `--home` 引数による絶対パスの明示的な伝搬仕組みを復元し、プロセスの実行権限に関わらず一貫したデータディレクトリを参照するように修正します。
