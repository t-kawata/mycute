# Release v0.24.150

## Summary
Implement M1-2 AdminFastTrack trust override with TrustAuditLog audit trail (RFC §8.2/§10.3), and optimize test runtime for the m1_1 suite.

## What's Changed
- **feat**: Add `apply_admin_fast_track` function that forces `HumanTrustLogistic.score` to 0.80, invalidates the applicability cache, and appends a `TrustAuditLog` record with full audit metadata (graph_id, event_type, actor_id, old/new values, timestamp, reason)
- **feat**: Implement `TrustProfile` (4-axis), `HumanTrustLogistic` (logistic update formula), `TrustAuditEvent` (14 variants), and `TrustAuditLog` (7 fields) type definitions matching RFC §8.2/§10.3
- **feat**: Add `MemoizedGraph` test stub with `invalidate_applicability_cache()` for M1-2 verification
- **feat**: Add 3 Safety Invariant constants: `TRUST_ADMIN_FAST_TRACK` (0.80), `HUMAN_TRUST_SCALE` (0.30), `HUMAN_TRUST_COLD_START` (0.50)
- **test**: Add 7 invariant tests (T1-T7) and 2 observational tests (OTS-1 n=1000, OTS-2 n=10000) for AdminFastTrack
- **perf**: Reduce m1_1 test suite runtime from ~25s to ~13s by lowering thread count, iteration count, and simulated time in OTS-1/OTS-2/OTS-4
