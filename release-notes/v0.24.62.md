# Release v0.24.62

## Summary
Fixed "Reset and Exit" functionality on Windows where the MYCUTE_HOME directory could not be fully deleted due to orphaned child processes and a held lock file handle.

## What's Changed
- fix: Reordered taskkill /F /T in BackendProcessGuard::drop() to run before parent process dies
- fix: Added release_lock() to close singleton lock file handle on Windows for directory deletion
- fix: Added image-name based taskkill fallback for orphaned Bifrost/ZeroClaw processes
- fix: Increased process termination wait time to 3 seconds on Windows for reliable cleanup
- refactor: Changed Box::leak to Box::into_raw in singleton.rs to allow lock handle reclamation
