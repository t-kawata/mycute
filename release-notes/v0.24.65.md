# Release v0.24.65

## Summary
Fix Windows Alt key leak during voice recognition by implementing defensive Alt UP injection with self-event markers and hook health monitoring.

## What's Changed
- **fix**: Windows — WH_KEYBOARD_LL hook no longer leaks Alt key events to foreground apps during voice recognition or AI post-correction (SendInput-based defensive Alt UP injection)
- **fix**: Self-event identification — all synthesized keyboard events now carry a `MYCUTE_EVENT_TAG` marker to prevent infinite loops in the hook procedure
- **fix**: `start_hook()` return value is no longer silently ignored; errors are logged and hook health is periodically checked (every 15s) with auto-reinstall on failure
- **refactor**: `process_alt_down()` decomposed into focused helper functions for readability
- **refactor**: Hardcoded VK codes replaced with named constants (`VK_CONTROL`, `VK_SHIFT`, `VK_LWIN`, `VK_RWIN`)
