# Release v0.24.155

## Summary
Implement M1.5-R1: Generic `InteractionRecord<TPayload>` type and `InteractionStatus` 7-state enum for RFC §12C Event Architecture foundation.

## What's Changed
- feat: add `InteractionPayload` trait, `InteractionRecord<TPayload>` generic struct, `HitlPayload` struct (RFC §12C)
- feat: extend `InteractionStatus` from 2 states to 7 states (Pending, AwaitingExternal, Resolved, TimedOut, Unreachable, ChannelClosed, Aborted)
- feat: add `type StoredInteraction = InteractionRecord<HitlPayload>` type alias with backward-compatible accessors (`request()`, `outcome()`)
- refactor: update all call-sites (human_channel.rs, recovery.rs, json_metadata_store.rs, metadata_store.rs) to use new payload wrapping
- test: add 7×7 transition matrix verification test
- test: add JSON serde round-trip test (n=1000, 100% success)
- docs: update Darvium-Tickets-v2.3.md spec to match RFC §12C
- docs: fix English→Japanese translation in RFC §9C markdown
