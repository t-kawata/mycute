# Release v0.24.131

## Summary
Darvium M-1-1: Implement static-threshold `EvaluateCandidatesStep` decision engine with `SearchOutcome` enum, threshold evaluation, and self-confidence discount scaffolding.

## What's Changed
- **feat**: Add `SearchOutcome` enum (6 variants) per RFC §13.3, with `WorkflowGraphId`, `GraphPatch`, `CompositionPlan`, `SearchAbortReason` supporting types
- **feat**: Implement `evaluate_candidates(best_score)` pure function with `EVALUATION_THRESHOLD = 0.50` static threshold — score ≥ 0.50 → `ReuseExisting`, else → `PatchExisting`
- **feat**: Implement `apply_self_conf_discount(raw_score)` auxiliary function for LLM self-confidence discounting (RFC §14.2)
- **feat**: Add `DarviumError::InvalidScore` variant for out-of-range score rejection
- **test**: Add 18 new tests across T1–T5 unit tests and OTS-1/OTS-2 observational tests
- **test**: Observational tests confirm decision boundary symmetry (P(reuse|center=0.5) ≈ 0.507) and β ∝ 1/σ² scaling law
- **refactor**: Fix `OscillationDetector::default()` clippy warning by implementing `Default` trait (Boy Scout)
