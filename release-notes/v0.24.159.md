# Release v0.24.159

## Summary
Implemented DarviumEventBus trait with 8 synchronous methods and FakeEventBus in-memory test implementation for Darvium Event Architecture (RFC §12C.5).

## What's Changed
- **feat**: Added `DarviumEventBus` trait (publish, open, resolve, reconnect, subscribe, replay, current_clock, quarantine_failed_events) by @Darvium
- **feat**: Added `FakeEventBus` in-memory implementation with Arc<Mutex<>> thread-safe state management
- **feat**: Added `InteractionId` newtype (From<String>, Into<String>, Display, Hash, Serialize, Deserialize)
- **feat**: Added `EventFilter` struct with kind_filter, since_vt, until_vt and `EventSubscription` trait
- **feat**: Expanded `DarviumError` with 3 EventBus-related variants (EventBus, EventNotFound, InteractionNotFound)
- **test**: Added 11 test cases covering all 8 DarviumEventBus methods, including n=1000 completeness and n=64 concurrent clock monotonicity
- **docs**: Completed ticket M1.5-R5 spec, plan, implementation, observation report, and review
