# Release v0.24.69

## Summary
Unified Alt/Option double-tap behavior across Windows and macOS: removed Ctrl/Cmd flush toggle and changed to double-tap detection for both Start and BufferFlush, with BufferFlush dedup protection added. Also improved Windows console output for debugging.

## What's Changed
- **feat**: Unified Alt/Option double-tap detection for both recording (BufferFlush) and non-recording (Start) states — removed Ctrl/Cmd implementation entirely
- **fix**: Added BufferFlush dedup guard (50ms window) to prevent double-firing from redundant event paths
- **refactor**: Inlined `handle_recording_alt()`, `confirm_double_tap()`, `update_last_press_time()`, `update_modifier_state()` in hotkey_win_hook.rs for readability
- **feat**: Added Windows console attachment (`AttachConsole` + `CONOUT$`) for debug log output in GUI-mode builds
- **chore**: Updated ticket queue status for #3
