# Release v0.24.75

## Summary
Added Windows voice input health check feature that detects and notifies about missing speech recognition configuration. Improved development workflow with safer sync/push Makefile targets.

## What's Changed
- **feat**: Windows voice input health check — detects three common misconfigurations (speech recognition model not installed, privacy toggle OFF, microphone access denied) via WinRT API calls
- **feat**: Health check notification dialog with i18n (EN/JA) — displayed at app startup and on Alt-recording start with direct `ms-settings:` URI links to each configuration page
- **feat**: `make sync` target — safe rebase-based pull with stash protection for multi-PC development workflow
- **enhance**: `make push` now detects unpulled remote changes and aborts with a message to run `make sync` first
- **enhance**: Updated SETUP.md with Windows voice input setup instructions for new contributors
- **dev**: Added development routine documentation (DEV_ROUTINE.md) for multi-PC synchronization workflow
