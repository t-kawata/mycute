# Release v0.24.187

## Summary

Implemented indirect reciprocity score (F-2) and BenevolenceScore aggregation (F-3) as pure functions in the reciprocity module, completing the core reciprocal scoring pipeline for Reciprocity-Aware Survival.

## What's Changed

- **feat**: Add `compute_indirect_reciprocity` (F-2) — computes global benevolence score from centrality, village participation, accepted rate, success rate, and harm penalty via sigmoid
- **feat**: Add `compute_benevolence_score` (F-3) — aggregates direct reciprocity, indirect reciprocity, and reputation into a unified benevolence metric
- **feat**: Add 6 calibration constants (`INDIRECT_BETA_CENTRALITY`, `INDIRECT_BETA_VILLAGE_PARTICIPATION`, `INDIRECT_BETA_ACCEPTED_RATE`, `INDIRECT_BETA_SUCCESS_RATE`, `INDIRECT_BETA_HARM_SCORE`, `REPUTATION_WEIGHT_REPUTATION`)
- **test**: Add 7 test cases (6 invariant tests + 1 observational instrumentation) with response surface grid and beta coefficient sweep
- **docs**: Mark M1.76-4 as completed in Darvium-Tickets-v2.3.md
