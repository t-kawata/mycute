# Release v0.24.84

## Summary
Added voice input orchestrator foundation — a generic routing layer that receives STT text, processes it through an Orchestrator pipeline, and returns responses in a chat-style overlay. Includes Ctrl+Alt/Control+Option hotkey detection, MockOrchestrator with rally-based completion, and full frontend overlay UI.

## What's Changed
- **feat**: Add `Orchestrator` trait and `MockOrchestrator` implementation with rally counting (3 rallies → task_completed), UUID session auto-generation, and empty-input validation (12 unit tests)
- **feat**: Add Ctrl+Alt (Windows) / Control+Option (macOS) simultaneous-press hotkey detection for orchestrator input, with atomic dedup and Alt double-tap conflict prevention
- **feat**: Add 3 Tauri commands — `create_orchestrator_session`, `orchestrator_process`, `destroy_orchestrator_session` — with parking_lot Mutex async-safe handling
- **feat**: Add `OrchestratorOverlay.vue` chat-style overlay with user/AI message bubbles, recording indicator, and close button (inherits OverlayView design: backdrop-filter blur, MPLUSRounded1c font, scale animation)
- **feat**: Add `ThinkingAnimation.vue` CSS dot-bounce animation component (swappable design)
- **feat**: Add `orchestrator-store.ts` Pinia store with session lifecycle management
- **feat**: Register OrchestratorOverlay in MainLayout.vue alongside existing OverlayView
- **feat**: Add `OrchestratorInput` HotkeyAction variant and Tauri event constants (display, text, response, task_completed)
- **chore**: Add ticket #8 tracking files (spec, plan, implementation summary, review report)
