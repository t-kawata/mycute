# Release v0.24.44

## Summary
Adds speech-to-text history persistence with overlay UI, storing up to 50 session transcripts in the database with clipboard copy and long-press placeholder support.

## What's Changed
- **feat:** Add STT history database table and migration (`stt_histories`)
- **feat:** Implement REST API endpoints for STT history (`GET /v1/stt/history`, `DELETE /v1/stt/history`) with utoipa documentation
- **feat:** Auto-save STT session text to database on `Stopped` event, trim to 50 records
- **feat:** Add history button to overlay controls (between font-size and close buttons)
- **feat:** Click history item to copy text to clipboard via Tauri invoke
- **feat:** Long-press (600ms) detection with placeholder alert handler
- **chore:** Update edition branding (icons, app name, settings)
