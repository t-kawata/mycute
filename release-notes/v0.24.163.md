# Release v0.24.163

## Summary
Implemented 4 domain-specific EventProjections (SearchTrace, TrainingRunLog, ReciprocityEvent, SearchRunLog) atop the R9 EventProjection framework, along with dual-path EventBus publish from DualStoreCoordinator.

## What's Changed
- Added `DomainProjection` struct with 4 constructors (`search_trace`, `training_run_log`, `reciprocity_event`, `search_run_log`)
- Added `initialize_domain_projections()` for bulk registration of all 4 projections into ProjectionCatalog
- Added optional EventBus publish path in `DualStoreCoordinator` (`with_event_bus()` builder)
- Added 9 integration test cases (TC-1 through TC-9) with n=1000 instrumentation confirming 100% filter accuracy and zero cross-projection contamination
- Fixed clippy lint: `.map_or(true, ...)` → `.is_none_or(...)` in `ProjectionEventFilter::matches()`
- Exported `DomainProjection` and `initialize_domain_projections` from the public API
