# Release v0.24.180

## Summary
Implemented property-based village invariant fuzzing with proptest (M1.75-10), adding 7 fuzz tests covering helper assignment, ConsistencyState filtering, HELP terminal non-reentrance, empty village fallback, maturity classification, and failing seed fixture roundtrip/replay regression.

## What's Changed
- **feat: property-based village invariant fuzzing (M1.75-10)**

  - Added F-1: helper assignment invariant — committed adults ≤ top_k
  - Added F-2: ConsistencyState filter — only Committed + Adult-maturity candidates pass
  - Added F-3: HELP terminal non-reentrance — no outgoing transitions from terminal states
  - Added F-4: empty village fallback — non-Committed candidates produce empty LocalVillage without panic
  - Added F-5: maturity classification — non-negative input never panics
  - Added F-6/F-7: FailingSeedEntry JSON roundtrip and replay fixture regression infrastructure
