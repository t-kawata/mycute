# Release v0.24.189

## Summary
Implement GC hazard with benevolence (F-7/F-8/F-9) — hazard rate with softplus non-negativity, GC probability, and survival probability as pure functions with benevolence-weighted lifecycle integration.

## What's Changed
- **feat**: Add `softplus` numerically stable helper — conditional branch for x > 0 vs x <= 0
- **feat**: Add `compute_gc_hazard` pure function (F-7) — λ_i^GC = softplus(λ₀ - γ_L·L_i - γ_B·B_i - γ_C·C_i^protect), always non-negative
- **feat**: Add `compute_gc_probability` pure function (F-8) — p_GC = 1 - exp(-λ·Δt) with [0, 1) range
- **feat**: Add `compute_survival_probability` pure function (F-9) — P_survive = exp(-λ·Δt) with (0, 1] range
- **feat**: Add GC_HAZARD_LAMBDA_0 (λ₀=1.0) and GC_HAZARD_GAMMA_LIFECYCLE (γ_L=0.5) calibration constants
- **refactor**: Replace hardcoded lambda_gc_base and gamma_lifecycle defaults with named constant references in ReciprocityLifecyclePolicy
- **test**: Add 8 test cases (TC-1–TC-8) including monotonicity assertions, survival probability invariance, and instrumentation with (L,B) 2D response surface + γ_B/γ_L sensitivity ratio sweep (n=10⁶)
