# Release v0.24.156

## Summary
Extended MetadataStore with 6 generic interaction methods (store/load/list/resolve/abort/reconnect) and InteractionFilter query struct, enabling domain-agnostic interaction management across HITL, Training, and Fusion domains.

## What's Changed
- Added `InteractionFilter` struct with status/channel_id/created_after/created_before/limit fields
- Added 6 generic interaction methods to `MetadataStore` trait (`store_interaction`, `load_interaction`, `list_interactions`, `resolve_interaction`, `abort_interaction`, `reconnect_interaction`)
- Refactored 4 existing HITL-specific methods into `#[inline]` default wrapper implementations
- Implemented all 6 methods in `InMemoryMetadataStore`, `JsonMetadataStore`, and `FailingMetadataStore`
- Added comprehensive test suite (T1-T8 structural + OTS-1 throughput measurement)
- Updated Darvium-Tickets-v2.3.md, RFC references, and table spec documentation
