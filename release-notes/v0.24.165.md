# Release v0.24.165

## Summary
Added SpacePositionEmbedding / VillagePosition type definitions and exponential smoothing position update dynamics as the foundation for the M1.75 Child Support Villages / HELP Consensus milestone (RFC §41B.2).

## What's Changed
- feat: Add `SpacePositionEmbedding` / `VillagePosition` / `PositionUpdatePolicy` type definitions with exponential smoothing position update dynamics
- feat: Add `VillageObservation` struct for decomposed observation locality components
- feat: Add `SpacePositionUpdatedPayload` and `SystemEvent::SpacePositionUpdated` variant for EventBus integration
- feat: Add `publish_position_update()` function for publishing position updates via `DarviumEventBus`
- feat: Add calibration candidates (`SPACE_POSITION_UPDATE_ALPHA`, `SPACE_POSITION_UPDATE_MIN_INTERVAL`) and safety invariant (`SPACE_POSITION_L2_EPSILON`)
- test: Add 19 unit tests covering boundary values, exponential convergence, L2 distance correctness, position update policy, EventBus publish completeness, and type construction
