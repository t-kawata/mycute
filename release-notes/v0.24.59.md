# Release v0.24.59

## Summary
Added "Complete Reset and Exit" feature that physically deletes the entire home directory including identity key pairs, enabling a full clean re-setup from scratch.

## What's Changed
- feat: Add `reset_and_exit` Tauri backend command implementing multi-phase cleanup (DB reset, Bifrost provider cleanup, backend process termination, home directory deletion with retry/fallback, app exit)
- feat: Add confirmation dialog with explicit warnings about identity (key pair) loss and network identification loss
- feat: Add loading indicator display during reset execution, matching the existing title-bar shutdown pattern
- feat: Register new dialog component in App.vue and new Tauri command in main_of_cl.rs
- feat: Add i18n translation keys (ja-JP/en-US) for the reset-and-exit flow
- refactor: SettingsApp.vue — reformat template for consistency; add reset-and-exit button in the danger zone section
