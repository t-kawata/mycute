# Release v0.24.166

## Summary
Implemented Child/Adult maturity classification and Local Village construction logic (Ticket M1.75-2) based on RFC §41B.3, enabling workflow maturity assessment and neighborhood-based village formation.

## What's Changed
- **feat**: Add `WorkflowMaturity` enum (`Child`/`Adult`) with `classify_maturity()` function based on experience count, trust composite score, and reputation final score thresholds
- **feat**: Add `LocalVillage` struct with `build_local_village_topk()` and `build_local_village_radius()` construction methods
- **feat**: Add `AdultCandidate` intermediate representation with `ConsistencyState` filtering for `Committed`-only adult candidates
- **feat**: Add 4 calibration candidate constants (`MIN_SURVIVAL_EXPERIENCE`, `E_ADULT_THRESHOLD`, `T_ADULT_THRESHOLD`, `R_ADULT_THRESHOLD`)
- **feat**: Export village module public API from lib.rs (`classify_maturity`, `filter_adult_candidates`, `LocalVillage`, `AdultCandidate`, `WorkflowMaturity`, village builders)
- **test**: Add 21 observational tests covering boundary conditions, distance-ordered selection, empty village, centroid computation, and combined filtering
