# Release v0.24.190

## Summary
Implemented F-10 child protection score `C_i^protect` that provides additional GC hazard reduction for child entities receiving help and showing growth, complementing the existing Grace Period.

## What's Changed
- **feat**: Add `compute_child_protection()` function (F-10) with 3 calibration constants (η₁=0.50, η₂=0.30, η₃=0.20)
- **test**: Add 7 test cases (TC-1 through TC-7) including monotonicity assertions, Grace Period independence verification, 3D response surface instrumentation, η sensitivity analysis, and stochastic range validation (n=10,000)
- **docs**: Add ticket M1.76-7 spec, plan, implementation summary, observation report, and review report
