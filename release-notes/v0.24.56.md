# Release v0.24.56

## Summary
Adds a voice input toggle switch to the title bar, allowing users to enable/disable hotkey-based voice recording directly from the UI. The toggle state persists across sessions.

## What's Changed
- **feat**: Add voice input toggle switch to the title bar with mic icon
  - Toggle switch positioned at the left edge of the title bar (absolute positioned, same pattern as the FAB on the right)
  - White mic icon appears to the right of the toggle when voice input is enabled
  - Only visible when logged in
  - State persisted to LocalStorage across sessions
- **feat**: Respect toggle state on login — `enable_hotkey_standby` is only called when the toggle is ON
- **refactor**: Reformat SCSS long expressions for readability (no behavior change)
