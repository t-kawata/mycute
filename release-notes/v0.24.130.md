# Release v0.24.130

## Summary
Implement SearchPolicyOscillation detection engine (M-1.5-3) that detects infinite oscillation between Refine and Retrieve states and forces transition to Abort.

## What's Changed
- **feat**: Add `OscillationDetector` struct with phase-based alternating transition counter to detect `Refine↔Retrieve` oscillation patterns
- **feat**: Add `attempt_transition` helper integrating oscillation detection with `SearchState::transition_to` for automatic forced Abort on oscillation
- **feat**: Add `TerminalTransitionReason::OscillationDetected` variant as a valid termination reason
- **feat**: Add `OSCILLATION_MAX_COUNT` calibration constant (default: 3) to `constants.rs`
- **test**: Add 12 unit tests (T1-T5) covering basic detection, reset on non-oscillation patterns, integration with state machine, saturation safety, and `can_terminate_with` validation
- **test**: Add 2 observational tests (OTS-1/OTS-2) for oscillation detection matrix and transition latency measurement
- **docs**: Mark ticket M-1.5-3 as completed in Darvium-Tickets-v2.3.md
