# Release v0.24.102

## Summary
Removed the obsolete cuber system (Rust `src/cuber/` and Go `mycute-go/`) as Darvium is its complete superset. Preserved lbug and S3Client behind a `darvium` feature flag for future reactivation.

## What's Changed
- **removed**: Entire `mycute-go/` directory (Go implementation of cuber)
- **removed**: All Rust `src/cuber/` modules (config, service, storage, tokenizer, event, error, consts)
- **removed**: 11 cubes endpoints from RT mode (handler, business logic, request/response types)
- **removed**: `cubes`, `cube_contributors`, `cube_lineages`, `cube_model_stats`, `exports` SeaORM entities
- **removed**: 5 cubes-related database migrations (purge_orphaned list updated for existing DBs)
- **removed**: `CuberSettings` from configuration system (mycute_settings, constants, settings.json.example)
- **removed**: S3Client and cube entity cleanup from Tauri system commands
- **refactored**: Added `[features]` section to Cargo.toml; made `lbug` and `rust-s3` optional dependencies behind `darvium` feature
- **refactored**: Gated `s3client` module with `#[cfg(feature = "darvium")]`
- **refactored**: Cleaned up entity mod declarations, prelude re-exports, and route registrations
