# Release v0.24.198

## Summary
Added M1.76-18 operational metrics observation pipeline for the reciprocity simulation, computing 9 RFC §41B.20.7 metrics including benevolent survival advantage, harmful GC rate, helper accept/abandon rates, and child survival rate.

## What's Changed
- **feat**: Added `ExtendedOperationalMetrics` struct holding 13 metric fields (4 percentile pairs + 5 single metrics)
- **feat**: Implemented 5 pure computation functions: `compute_benevolent_survival_advantage`, `compute_harmful_gc_rate`, `compute_helper_accept_rate`, `compute_help_abandon_rate`, `compute_child_survival_rate`
- **feat**: Added `ReciprocityMetricsObserver` with `observe()` and `print_csv()` methods for simulator integration
- **test**: Added 10 tests (T10-T19) covering boundary values, empty data graceful handling, observer integration, top/bottom 20% split correctness, CSV output format, and backward compatibility
- **chore**: Added `BENEVOLENT_TOP_FRACTION` and `BENEVOLENT_BOTTOM_FRACTION` constants as Safety Invariants
