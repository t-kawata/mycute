# Release v0.24.172

## Summary
Implement village stability / dynamicity metrics (RFC §41B.14-15) including position drift, Jaccard overlap, village churn, helper weight JSD, child survival rate, and child maturation time, with EventProjection integration as VillageObservationLog.

## What's Changed
- **feat**: Define `VillageMetrics`, `VillageMetricsWindow`, `VillageMetricsSnapshot` types with p50/p95 aggregation
- **feat**: Implement `compute_position_drift` (eq 41B-21), `compute_village_jaccard` (eq 41B-22), `compute_village_churn` (eq 41B-23), `compute_helper_jsd`, `compute_child_survival_rate`, `compute_child_maturation_time`
- **feat**: Add `VillageEvent::TickCompleted` variant, `DarviumEventKind::Village`, and `DomainProjection::village_observation_log()` as 5th EventProjection
- **feat**: Register `village_observation_log` in `initialize_domain_projections()` with additive variant-only extension
- **test**: Add 13 invariant tests (T-1~T-13) and 3 observation tests (T-O1~T-O3) for all metric functions
- **test**: Add 4 EventProjection integration tests (T-E1~T-E4) verifying materialization, domain separation, catalog registration, and clock key alignment
- **chore**: Add 4 village metrics calibration candidates to `constants.rs`
