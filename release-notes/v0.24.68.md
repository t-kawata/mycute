# Release v0.24.68

## Summary
Fix Windows `reset_and_exit` to properly terminate Bifrost/ZeroClaw backend processes and delete the home directory. Refactor inline process management into reusable utilities with comprehensive test coverage.

## What's Changed
- **fix**: Replace error-swallowing `let _ =` taskkill with logged `match` in BackendProcessGuard::drop() for diagnostic visibility
- **fix**: Replace fixed 3s sleep with active polling (`wait_for_process_exit`) to wait for Bifrost/ZeroClaw termination on Windows
- **fix**: Add image-name based process kill safety net (`kill_process_by_image_name`) in reset_and_exit Phase 7.5
- **refactor**: Extract directory deletion logic into reusable `delete_home_directory()` with retry + OS fallback
- **refactor**: Extract `release_and_delete()` for Windows singleton lock release before directory deletion
- **test**: Add 8 unit tests for Windows process management utilities (kill/find/wait by image name/PID)
- **test**: Add 7 cross-platform unit tests for `delete_home_directory` (empty, nested, unicode, readonly, hidden, idempotent, nonexistent)
- **test**: Add integration test (spawn real ping.exe → kill → verify directory deletion)
