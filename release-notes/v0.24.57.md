# Release v0.24.57

## Summary
Removed all dead `__harunohi`-prefixed SCSS classes left over from the deleted Harunohi job market model, and renamed all remaining `__harunohi` class references to `__mycute` for consistent project naming.

## What's Changed
- **refactor**: Removed dead `__harunohi-*` CSS classes (icon helpers, badge-window, ruler, tabs, tabpanel, swipe, gamaguchi, overlay, btn-icon, header-btn-icon, selectable, login-page-box, dec-circle-left) — approximately 450 lines of unused styles eliminated
- **refactor**: Renamed all remaining `__harunohi` → `__mycute` across 17 source files (185 occurrences) including SCSS definitions, Vue templates, TypeScript class bindings, and SCSS variables
- **refactor**: Renamed `@keyframes harunohi-fade-in` → `mycute-fade-in` for naming consistency
- **chore**: No visual or behavioral changes — all renames are class-name-only, and dead removals were verified via grep-based static analysis with zero false positives
