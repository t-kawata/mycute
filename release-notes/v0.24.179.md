# Release v0.24.179

## Summary
Added small perturbation experiment suite (M1.75-9) to Darvium replay engine for village stability verification, and fixed SherpaOnnx VAD initialization failures on Windows systems with non-ASCII user profile paths.

## What's Changed
- **feat(darvium)**: Implement 5 perturbation generators (embedding noise, trust delta, single edge patch, usage increment, helper quarantine) for village stability testing
- **feat(darvium)**: Add `compare_perturbed_metrics` function and `StabilityRegressionSummary` struct for baseline/perturbed trace comparison
- **feat(darvium)**: Add 10 perturbation tests (P-1~P-8 invariants, O-P1 sigma sweep, O-P2 quarantine duration sweep) with observational CSV output
- **feat(darvium)**: Register 5 perturbation constants with classification tags in constants.rs
- **fix(darvium)**: Fix clippy `ptr_arg` warning in `tie_break_sort` signature (`&mut Vec` → `&mut [RankedCandidate]`)
- **fix(vad)**: Resolve SherpaOnnx VAD crash on Windows with Japanese user names by implementing 8.3 short path fallback and PROGRAMDATA ASCII-safe model cache
- **feat(downloader)**: Add SHA256 checksum verification for downloaded models with automatic re-download on corruption
- **build**: Enable `fileapi` feature in winapi dependency for GetShortPathNameW
