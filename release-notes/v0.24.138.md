# Release v0.24.138

## Summary
This release implements the AG-06 and AG-07 hard gates for embedding model and template version mismatch detection. Candidates with version mismatches are now strictly blocked at the applicability check stage with zero false positives.

## What's Changed
- **feat**: Implement `EmbeddingChannelVersion` and `EmbeddingVersions` structs for RFC §11 compliance
- **feat**: Add `check_ag06()` — semantic channel model version hard gate (pixel-perfect comparison)
- **feat**: Add `check_ag07()` — structural channel model + template version hard gate
- **feat**: Extend `QueryRepresentation` with `task_embedding_version` and `design_embedding_version` fields
- **test**: Add 17 new tests (12 unit + 5 integration/observation) including 10,000-iteration false positive rate validation
- **test**: Observational tests confirm P_pass(E=0)=1.00, P_pass(E≥1)=0.00 ideal step function
- **docs**: Add ticket M-0.5-3 spec, plan, observation report, and review artifacts
