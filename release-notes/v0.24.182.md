# Release v0.24.182

## Summary
Integrated 4 experiment systems (replay, perturbation, fuzzing, calibration) into a unified `VillageExperimentReport` with Markdown/JSON output format and experiment lineage management.

## What's Changed
- **feat**: Add `VillageExperimentReport` structure integrating replay metrics, perturbation results, calibration reports, and failing seeds into a single report
- **feat**: Implement Markdown (8-section) and JSON report writers with file output utilities
- **feat**: Add `ExperimentLineage` and `FsLineageStore` for experiment ancestry tracking and circular reference detection
- **feat**: Promote `FailingSeedEntry` from `#[cfg(test)]` internal struct to public API with serde support
- **feat**: Add serde `Serialize`/`Deserialize` derives to `StabilityRegressionSummary`, `SummaryMetrics`, `VillageMetricsSnapshot`, and calibration types for report serialization
- **feat**: Add `rules/darvium/experiment-reporting.md` documenting report format, lineage naming, and JSON schema
- **test**: 18 new tests covering report generation, JSON roundtrip, file I/O, lineage tracking, and cross-system integration
