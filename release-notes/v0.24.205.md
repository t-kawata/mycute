# Release v0.24.205

## Summary
Implement Kind World (KW1) threshold constants and J_kw objective function for the Reciprocity-Aware Survival milestone (M1.76), and resolve all cargo check/test/clippy warnings across the codebase.

## What's Changed
- **feat**: Add 16 Kind World constants (8 condition thresholds, 2 village constants, 6 J_kw alpha weights) to `constants.rs`
- **feat**: Create `kind_world` module with `KindWorldMetricsInput`, `KindWorldAssessment`, `MagnificentSevenParams` structs and `compute_kind_world_objective()` pure function
- **feat**: Add 11 tests (10 invariant tests + n=10,000 observational random test) for KW1
- **refactor**: Rename deprecated `rng.gen()` → `rng.random()` across `simulation.rs` and `kind_world.rs`
- **refactor**: Fix `clippy::ptr-arg` (`&mut Vec` → `&mut [_]`) and `clippy::manual-is-multiple-of` in `simulation.rs`
- **refactor**: Add `#[cfg(test)]` gating to `phase_rollout_tests` module in `calibration.rs`
- **refactor**: Add `Default` impl for `PhaseGate` struct
- **fix**: Remove unused `mut` qualifier and unused imports in `event.rs` and `report.rs`
