# Release v0.24.141

## Summary
Implemented M0-2 GenerateNew safety guard logic with side-effect-based human review enforcement across Production/Training/SafeSandbox planes, and optimized slow observational tests for faster CI feedback.

## What's Changed
- **feat**: Add `SideEffectSet`, `PlaneKind`, `SafeSandboxScope` types and `guard_new_proposal_or_review` public API for GenerateNew safety enforcement (RFC §6.1 / §13.6 / §16A)
- **feat**: Production plane blocks all GenerateNew proposals with `NeedsHumanReview`; Training/SafeSandbox planes allow conditional auto-approval within safe scope boundaries
- **perf**: Fix embedding collision test O(n²) → O(n log n) sort-and-scan, reducing runtime from ~30s to 0.07s
- **perf**: Reduce OTS iteration counts across composition and simulated-ranker tests — full suite drops from ~31s to ~1.6s (~20x improvement)
- **chore**: Add `**/.DS_Store` to .gitignore
- **chore**: Update ticket queue with M0-2 completion status
