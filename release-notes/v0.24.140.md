# Release v0.24.140

## Summary
Implement CompositionPlan variable scope static validator (M0-1) with RFC §13.3/§6.4 compliance, including V-03/V-04 data-flow integrity checks and frontier-based parallel execution scope leakage detection.

## What's Changed
- **feat**: CompositionPlan 変数スコープ静的バリデータを実装 (RFC §13.3/§6.4)
  - Expanded `CompositionPlan`, `EdgeMeta`, `WorkflowNode` from unit structs to full RFC-compliant types
  - Added `VarDecl` and `VarType` types per RFC §6.1
  - Implemented `validate_composition_plan()` — V-03 (from_var == output_var) and V-04 (to_var in inputs) checks across all composition edges
  - Implemented `detect_frontier_leakage()` — scope leakage detection on parallel-ready frontiers
  - Added 15 tests (12 unit + 3 observation) with 100% capture rate on 3.2M injected violations
  - Confirmed linear O(E) scaling and bounded worst-case steps via statistical ensembles (n=10,000)
  - Updated `graph_store.rs` tests to use new enum variants; all 387 tests pass
