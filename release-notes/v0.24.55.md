# Release v0.24.55

## Summary
Removed all traces of the legacy Harunohi job market model from both backend and frontend, including 13 database tables, 14 Vue components, and associated types/stores.

## What's Changed
- refactor: Remove 13 old job market entities and database tables (badges, belongs, burned_keys, flushes, jobs, match_statuses, matches, payments, payouts, points, pools, usr_badges, works)
- refactor: Remove 12 deprecated columns from usrs table
- refactor: Delete 14 Vue components related to badge/job-market UI
- refactor: Remove badge types, sample data, and store state from frontend
- refactor: Remove BADGE tab from navigation enum
- refactor: Clean up old commented-out code in MainLayout
- fix: Fix TypeScript strict null check in OverlayView
