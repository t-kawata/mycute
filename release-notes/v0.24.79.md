# Release v0.24.79

## Summary
Fixed Windows release build failure caused by missing sharp native binary for icon generation. Added automatic recovery mechanism and corrected pnpm architecture configuration for Windows.

## What's Changed
- fix: Windows release build failure due to missing sharp native binary (`sharp-win32-x64.node`) by @kawat
- fix: Added `win32` to pnpm's `supported-architectures` in `web/.npmrc` to ensure Windows native binaries are downloaded
- fix: Added automatic sharp binary rebuild step in `generate-icons` Makefile target as a safety net
- chore: Edition configuration synced (MYCUTE edition settings applied across all config files)
