# Release v0.24.87

## Summary
Fixed Windows Ctrl+Alt orchestrator hotkey not working when the mycute window has focus, by adding Ctrl key state tracking to the rdev listener and GetAsyncKeyState polling threads.

## What's Changed
- **fix**: Windows Ctrl+Alt orchestrator hotkey now works regardless of window focus
- **refactor**: Shared orchestrator combo detection across all three input paths (WH_KEYBOARD_LL hook, rdev listener, GetAsyncKeyState polling) with unified cooldown and double-fire prevention
