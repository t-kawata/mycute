# Release v0.24.114

## Summary
Implemented RetrievalPrimitive trait and core data type definitions for Darvium Layer 3a (GMR Retrieval), establishing the abstract interface foundation for SearchWorkflow integration.

- **feat**: Add `RetrievalPrimitive` trait with `search_workflows()` method (RFC §13.4)
- **feat**: Define `QueryRepresentation` struct with 10 fields including v1.8 knowledge-aware extension enums (RFC §9.4/§9.5)
- **feat**: Add `RetrievalPolicy`, `RankedCandidate`, `CandidateSet` data structures
- **feat**: Add `QueryType`, `FreshnessRequirement`, `EvidenceStrictness`, `DriftSensitivity` enums
- **feat**: Implement `Default` and `new()` constructors with RFC-specified defaults
- **test**: Add 8 unit tests covering trait object safety, field access, default values, exhaustive enum matching, and construction patterns
- **chore**: Add `.gitignore` for Darvium crate (target, dist, node_modules)
- **chore**: Create ticket management structure for M-2 milestone tracking
