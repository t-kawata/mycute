# Release v0.24.151

## Summary
Implemented M1-3 debounce logic for asynchronous human feedback injection, completing the TrustUpdate state machine with debounce cache invalidation control (RFC §10.5).

## What's Changed
- Added `TrustUpdate` enum with Operational/Human/Semantic variants for typed trust updates
- Implemented `TrustProfile::composite()` weighted score computation (RFC §10.4)
- Implemented `MemoizedGraph::update_trust()` with debounce logic — cache invalidation is skipped when composite score delta is below `TRUST_DEBOUNCE_DELTA (0.05)` for Human updates
- Added `TRUST_DEBOUNCE_DELTA = 0.05` calibration candidate constant
- Added 8 invariant tests (T1-T8) and 3 observational tests (OTS-1-OTS-3) for debounce logic
- Fixed `HumanTrustLogistic::default()` to implement `impl Default` trait (clippy fix)
- Exposed `TrustUpdate` in the public API
