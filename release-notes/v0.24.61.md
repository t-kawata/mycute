# Release v0.24.61

## Summary
Replaced the "Always On Top" toggle with a "Pin During Voice Input" setting, improved OpenAI STT event handling with proper completion detection, and updated README documentation.

## What's Changed
- **feat**: Replace "Always On Top" FAB button with "Pin During Voice Input" setting toggle
- **feat**: Add `pin_during_voice` flag to MycuteManager with backend/frontend sync
- **feat**: Conditionally pin/unpin window only when `pin_during_voice` is enabled
- **fix**: Add `SttPending`/`SttCompleted`/`DecorationPartial` events for reliable STT lifecycle tracking
- **fix**: Isolate decoration animation frames from `current_text` updates
- **fix**: Ensure `SttCompleted` is sent after `ForceClearDecoration` and on `PartialResult`/`FinalResult`
- **fix**: Reduce `STT_DECORATION_INTERVAL_MS` from 250ms to 180ms for smoother animation
- **fix**: Remove unused `MONITORING_ACTIVE` import in Windows hotkey hook
- **docs**: Multiple text corrections in README-NECO-ASOVI.md
