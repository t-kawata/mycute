# Release v0.24.123

## Summary
Add Clock/VirtualClock abstract trait for deterministic time handling and enforce UTC as the mandatory time reference across all Darvium specification documents.

## What's Changed
- **feat**: Add `Clock` abstract trait with `VirtualClock`, `SystemClock`, and `FrozenClock` implementations for deterministic time abstraction (`src/clock/mod.rs`) (#5)
- **docs**: Enforce UTC as mandatory time reference (MUST) across Darvium-RFC-0001, Darvium-Tickets-v2.3, and table/struct specification documents
- **test**: Add 16 unit tests (T1-T16) covering trait bounds, object safety, deterministic advance, saturation arithmetic, monotonicity, and observational verification
