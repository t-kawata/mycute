# Release v0.24.206

## Summary
Implemented KW2 ecosystem growth metrics instrumentation (5 pure functions + observer) for Kind World ecosystem evaluation, updated KW3 village specification per RFC §41B.3, and applied broader cargo fmt code formatting.

## What's Changed
- **feat**: Add M1.76-KW2 ecosystem growth metrics — `EcosystemGrowthMetrics` struct, 5 computation functions (`compute_population_growth_rate`, `compute_capability_coverage_shannon`, `compute_reuse_ratio`, `compute_cost_efficiency`, `compute_benevolent_vs_non_benevolent_coverage_ratio`), and `EcosystemGrowthObserver` with CSV output (RFC §15.9.3)
- **feat**: Add `ECOSYSTEM_GRID_DIVISIONS = 10` constant for Shannon diversity grid quantization
- **docs**: Update KW3 spec to use temporary village assignment vectors instead of `SimWorkflowState` field per RFC §41B.3 (village as derived neighborhood)
- **style**: Apply consistent code formatting across `event.rs`, `calibration.rs`, `simulation.rs`, `report.rs`, `event_channel.rs`, `lib.rs`, `reciprocity.rs`
