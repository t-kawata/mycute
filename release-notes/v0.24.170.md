# Release v0.24.170

## Summary
Implement helper weighting (Eq 41B-18) and bounded remote exploration (Eq 41B-19) from RFC §41B.12, replacing unweighted adult_ids selection with a full pipeline of distance-decay weighting, trust/reputation modulation, epsilon-greedy exploration mixing, and hard filter exclusion.

## What's Changed
- feat: add `HelperWeight`, `HelperSelectionPolicy` type definitions for helper selection
- feat: implement `compute_helper_weights` — normalized weight function with distance decay β, trust exponent μ, reputation exponent ν (RFC §41B-18)
- feat: implement `mix_with_remote_exploration` — epsilon-greedy mixing of local and remote weights (RFC §41B-19)
- feat: implement `select_helpers` — full pipeline: hard filter → distance calculation → weight computation → exploration mix → top-k selection
- feat: add 5 calibration constants (β, μ, ν, ε, top_k) to constants.rs
- test: add 8 invariant tests (T-1 through T-8), 2 observation tests (T-O1 β-ε grid sweep, T-O2 distance-quality tradeoff), 1 instrumentation summary
