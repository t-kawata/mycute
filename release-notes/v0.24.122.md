# Release v0.24.122

## Summary

Implemented EmbeddingProvider abstract trait with FakeEmbeddingProvider and ConstantEmbeddingProvider for deterministic embedding vector generation in the Darvium crate. Includes Boy Scout improvements to error.rs for embedding error section consolidation.

## What's Changed

- **feat**: Add `EmbeddingProvider` trait (`embed`, `embed_dimension`) with `Send + Sync` bounds and object safety in `darvium/src/llm/mod.rs`
- **feat**: Add `FakeEmbeddingProvider` — deterministic pseudo-embedding generator using FNV-1a hash + MMIX LCG, no external RNG dependency
- **feat**: Add `ConstantEmbeddingProvider` — returns constant vector for all inputs (test utility)
- **feat**: Add `DarviumError::Embedding(String)` variant and consolidate embedding errors under dedicated `// === Embedding ===` section
- **feat**: Add `FAKE_EMBEDDING_DEFAULT_DIMENSION` constant (384)
- **test**: Add 15 tests (T1-T15) covering trait bounds, determinism, collision resistance, dimension correctness, edge cases, and statistical distribution
- **chore**: Update Darvium-Tickets-v2.3.md to mark M-2-1.7 as completed
- **refactor**: Consolidate store module formatting and type definitions
