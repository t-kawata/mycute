# Release v0.24.70

## Summary
Replaced Windows "Complete Reset and Exit" with a clipboard-based cleanup command approach, since reliable process termination and directory deletion are fundamentally impossible on Windows due to mandatory file locking and taskkill privilege limitations.

## What's Changed
- **feat**: Added `copy_cleanup_cmd_for_windows` Tauri command — copies `rmdir /s /q` command for MYCUTE_HOME to clipboard on Windows
- **feat**: Added batch file cleanup approach (`spawn_cleanup_bat`) as a best-effort safety net on Windows reset
- **feat**: Split frontend button — Windows shows "Get Cleanup Command", macOS/other keeps "Complete Reset and Exit"
- **fix**: Changed taskkill `.status()` to `.output()` across `process.rs` for proper stderr capture and logging
- **fix**: Added `ChildProcessGuard::drop()` logging for taskkill spawn results
- **refactor**: Made Windows `reset_and_exit` return early with unsupported error
- **test**: Added batch template validation tests (path quoting, retry logic, lock file, self-deletion)
- **test**: Added `escape_bat_string` tests and `spawn_cleanup_bat` path validation tests
- **docs**: Updated ticket #4 status to done
