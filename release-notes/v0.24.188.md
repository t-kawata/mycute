# Release v0.24.188

## Summary
Implement F-4/F-5 reputation recompute (recompute_reputation) with 4-component weighted aggregation and experience count saturation normalization. Fix ReciprocityLifecyclePolicy default values that were referencing incorrect constants.

## What's Changed
- **feat**: Add `recompute_reputation` pure function (F-4) — aggregates direct reciprocity, indirect reciprocity, experience norm, and inherited score with configurable theta weights, clamped to [0, 1]
- **feat**: Add `compute_experience_norm` pure function (F-5) — exponential saturation normalization to prevent seniority entrenchment
- **feat**: Add `ReputationInputs` lightweight struct for F-4 input components
- **feat**: Add 5 new calibration constants (REPUTATION_THETA_DIR, _IND, _EXP, _INHERIT, KAPPA_E)
- **fix**: Correct `ReciprocityLifecyclePolicy` defaults — theta_dir was incorrectly referencing RECIPROCITY_ALPHA_HELP (α_h=1.0); theta_exp/theta_inherit were raw literals; kappa_e field was missing
- **test**: Add 7 test cases (TC-1–TC-7) including invariant assertions and instrumentation with kappa_E sweep + simplex sampling
- **chore**: Update ticket queue status for M1.76-5
