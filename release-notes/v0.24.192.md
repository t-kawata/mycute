# Release v0.24.192

## Summary
Implement ReciprocityEvent ingestion pipeline with reputation/hazard recompute, enabling event store management, bulk profile recalculation, and deterministic replay verification for all graphs.

## What's Changed
- Add `ReciprocityEventStore` struct for in-memory event management keyed by source_graph_id
- Add `GraphMetrics` struct providing F-2 (indirect reciprocity) and F-4 (reputation) inputs
- Add `ingest_reciprocity_event()` for DarviumEvent→ReciprocityEvent materialization
- Add `recompute_all_profiles()` bulk pipeline chaining F-1→F-2→F-4/F-5→F-3 for all graphs
- Add `recompute_all_gc_hazards()` bulk GC hazard computation with external child_protection injection
- Add `ReciprocityReplaySnapshot` / `ReciprocityDiffReport` / `compute_replay_comparison()` for deterministic replay verification
- Add 9 tests (R11-T1 through R11-T9) including boundary, deterministic replay, diff detection, and response surface observation
- Add `RECIPROCITY_EVENT_PROJECTION_NAME` and `RECIPROCITY_STORE_INITIAL_CAPACITY` constants
