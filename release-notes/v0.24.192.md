# Release v0.24.192

## Summary
Implement benevolence-aware remote exploration (F-13) from RFC §41B.20.3, enabling selective remote helper search based on local benevolence levels.

## What's Changed
- Add `compute_benevolence_aware_remote_exploration()` function computing ε_remote with need and benevolence adjustment
- Add `REMOTE_EXPLORATION_NEED_COEFF` (a₁) and `REMOTE_EXPLORATION_BENEVOLENCE_COEFF` (a₂) constants to `ReciprocityLifecyclePolicy`
- Add 8 tests including boundary, monotonicity, backward compatibility, bounded random sampling, and 2D response surface observation
