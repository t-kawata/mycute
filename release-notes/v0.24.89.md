# Release v0.24.89

## Summary
Improve startup reliability by automatically cleaning up orphan daemon processes (Bifrost, ZeroClaw, Core) before acquiring the singleton lock, and fix error swallowing in the lock mechanism to report actual OS error codes.

## What's Changed
- **fix**: Add `cleanup_orphan_processes()` to kill leftover daemon processes at startup, preventing port conflicts from crashed instances
- **fix**: Fix error swallowing in `acquire_lock()` — differentiate "another instance running" from actual OS errors (e.g., permission denied)
- **fix**: Windows CIM fallback when `taskkill /F /IM` fails with access denied
- **refactor**: Call orphan cleanup from both GUI (CL) and server entry points before singleton lock acquisition
