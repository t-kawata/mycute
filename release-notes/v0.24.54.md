# Release v0.24.54

## Summary
Fixed dual-management inconsistency between MYCUTE DB and Bifrost for LLM provider configurations. Providers are now synchronized from DB to Bifrost on startup, and cleaned up from Bifrost on application reset.

## What's Changed
- Added startup sync to restore Bifrost provider configurations from the database on service start
- Added Bifrost provider cleanup to the application reset flow to prevent orphaned configurations
- Added internal API endpoint (`POST /api/v1/internal/bifrost/clear-providers`) for reset-time Bifrost cleanup
- Fixed HTTP response body not consumed in `delete_bifrost_providers` by using reqwest directly instead of the Axum streaming proxy
- Improved reset logging to distinguish between successful and partial cleanup outcomes
