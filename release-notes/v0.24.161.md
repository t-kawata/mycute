# Release v0.24.161

## Summary
Reconfigure HumanChannel as an EventBus/MetadataStore HITL adapter per RFC §12B.3, enabling event-driven HITL interactions through DarviumEventBus while maintaining full backward compatibility with existing FakeHumanChannel usage.

## What's Changed
- **feat**: Add `EventBusHumanChannel` — HumanChannel implementation that delegates notify/communicate/reconnect to `DarviumEventBus` + `MetadataStore`
- **feat**: Add `HumanChannelConfig` with optional `event_bus` and `interaction_store` fields for adapter mode configuration
- **feat**: Add `FakeHumanChannel::with_config()` constructor for EventBus adapter mode with backward-compatible default
- **refactor**: Convert `RefCell` to `Mutex` across 3 MetadataStore implementations (`InMemoryMetadataStore`, `JsonMetadataStore`, `FailingMetadataStore`) for thread safety under `Arc<dyn MetadataStore + Send + Sync>`
- **test**: Add 12 unit tests (T1-T11) covering adapter notify/communicate/reconnect lifecycle
- **test**: Add 3 observation tests (OTS-1/OTS-2) with n=8,192 serde roundtrip and n=100 legacy-vs-adapter consistency verification
- **docs**: Add release notes for v0.24.161
