# Release v0.24.161

## Summary
Introduce EventChannel trait and StdinoutEventChannel with canonical JSON Lines protocol for Darvium Event Architecture external integration. Includes Boy Scout formatting improvements across multiple source files.

## What's Changed
- Add `EventChannel` trait (send/receive/flush, Send+Sync, object-safe) for external event transport (RFC §12D)
- Add `StdinoutEventChannel<R, W>` implementing canonical JSON Lines protocol with 7 message types (event.publish, interaction.open, interaction.reply, interaction.reconnect, subscribe, ack, error)
- Add `CompatMode::Enabled/Disabled` for backwards compatibility with legacy HITL JSON Lines protocol
- Add `WebSocketEventChannel` type definition (implementation deferred to M1.76-21)
- Add `Subscription` struct for event subscription state management
- Add `DarviumError::EventChannel(String)` variant
- Run `cargo fmt` formatting improvements across event.rs, types.rs, store/, human_channel.rs, recovery.rs
- Update Darvium-Tickets-v2.3.md and tickets/queue.md for M1.5-R8 completion
