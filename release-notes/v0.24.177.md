# Release v0.24.177

## Summary
Implemented 4-layer search pipeline (retrieve_top_level_candidates) with WorkflowCache + RepositoryPair architecture per v2.3-j RFC §8, featuring semantic retrieval, metadata filtering, GED-based structural scoring, and applicability evaluation.

## What's Changed
- **feat**: New 4-layer search pipeline (`retrieve_top_level_candidates`) with 5 stages: Semantic Retrieval → Metadata Filter → Cheap GED Filter → Full GED Rerank → Applicability Evaluation
- **feat**: `evaluate_candidate` implementing RFC §11.3 formulas (6)-(10) for semantic, structural, and applicability scoring
- **feat**: `WorkflowCache::get_or_load` lazy load from `RepositoryPair` on cache miss (previously a stub)
- **feat**: `GraphStore` trait extended with `load_embedding` and `store_workflow_graph_with_id`
- **feat**: `DualStoreCoordinator` exposes `load_memoized_graph` and `store_memoized_graph` for MemoizedGraph persistence
- **feat**: `MemoizedGraph` gains `task_embedding` field for semantic similarity computation
- **test**: 18 pipeline tests (T1-T18) covering happy path, cache hit/miss, monotonicity invariant, edge cases, tie-break stability
