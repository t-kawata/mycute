# Release v0.24.48

## Summary
FAB button now opens STT overlay with history panel directly. Text area auto-hides when history is shown to prevent visual overlap. macOS development mode skips prelaunch permission checks. Added i18n support for the new button label.

## What's Changed
- feat: FAB button title bar action now opens overlay with history panel directly, with multi-language label "Open Voice Input History" / "音声入力履歴を開く"
- feat: History panel auto-hides the text display area and controls (v-if) to eliminate visual overlap
- fix: macOS prelaunch checks now skip when running outside .app bundle (development mode)
- fix: Replaced custom dialog backdrop with Quasar QDialog, fixing z-index, border-radius, and Vue warning about non-prop attributes
- i18n: Added app.fab.overlay.openHistory key in English and Japanese
