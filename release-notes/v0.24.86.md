# Release v0.24.86

## Summary
Refined the orchestrator voice input system with a reliable flush mechanism, enhanced overlay design, and cross-platform hotkey guards.

## What's Changed
- **feat**: Abstracted flush mechanism (`request_flush()` / `build_flush_text()`) for unified STT completion waiting across all voice input features
- **feat**: Added orchestrator overlay with full-width markdown-rendered assistant messages and bubble-style user messages
- **feat**: Added shared `SttRecognizerDisplay` component for real-time STT text visualization
- **feat**: Added mock orchestrator with locale-aware responses and rally-count completion
- **fix**: Prevented OrchestratorInput double-fire with 150ms cooldown on macOS and Windows
- **fix**: Added `ORCHESTRATOR_ACTIVE` flag to prevent hotkey handler collisions between legacy voice input and orchestrator
- **fix**: Legacy overlay text now properly cleared on new recording session start
- **refactor**: Applied Boy Scout Rule cleanup to event loop code (extracted guards, improved comment accuracy)
- **style**: Assistant messages rendered full-width with white text-shadow for readability
