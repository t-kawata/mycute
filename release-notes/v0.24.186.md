# Release v0.24.186

## Summary
Implemented the direct reciprocity score `compute_direct_reciprocity` (F-1) pure function, completing ticket M1.76-3. This is the foundational computation engine for Reciprocity-Aware Survival as defined in RFC §15.10.2.

## What's Changed
- **feat**: Added `compute_direct_reciprocity` pure function implementing formula F-1 (logistic sigmoid over weighted event contributions with time decay)
- **feat**: Added `src/reciprocity.rs` module with helper functions `event_kind_weights`, `logistic_sigmoid`, and `time_decay`
- **feat**: Included 6 instrumentation tests (TC-1 through TC-6) validating monotonicity, time decay, coefficient sign, range constraints, and ρ_dir sweep
- **chore**: Marked ticket M1.76-3 as completed in Darvium-Tickets-v2.3.md and queue.md
