# Release v0.24.90

## Summary
Fixed Windows Ctrl+Alt hotkey detection reliability by adding missing combo checks in rdev and polling paths, and properly propagating hook event parameters through the hook chain.

## What's Changed
- fix: Added missing `check_orchestrator_combo()` call in rdev Alt KeyPress handler to detect Ctrl+Alt press when Ctrl precedes Alt
- fix: Added missing `check_orchestrator_combo()` call in GetAsyncKeyState polling Alt DOWN handler for the same scenario
- fix: Added Ctrl key release tracking (VK_CONTROL, VK_LCONTROL, VK_RCONTROL) in WH_KEYBOARD_LL WM_KEYUP handler to prevent MOD_CTRL from lingering in CURRENT_MODIFIERS
- fix: Changed `process_alt_down()` and `process_alt_up()` to propagate original event parameters to `CallNextHookEx` instead of hardcoded zero values, ensuring downstream hooks receive correct event information
