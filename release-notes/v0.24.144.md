# Release v0.24.144

## Summary
Implemented GraphPatch/PatchOperation/PatchError types and patch-time validation (RFC §12) with property-based observational tests proving cycle detection completeness and noise injection safety.

## What's Changed
- **feat(darvium)**: Add `PatchOperation` enum (7 variants), `PatchConfidence` geometric mean with dynamic weight switching, `GraphPatch` struct, and `PatchError` enum (6 variants) per RFC §12.1-12.6
- **feat(darvium)**: Implement `apply_patch_atomic` 4-phase (clone→apply→validate→swap) and `validate_patch_result` 3-stage validation (DAG+var_scope+subworkflow_refs) per RFC §12.4/§14.2
- **feat(darvium)**: Add 8 patch-related constants to `constants.rs` (PATCH_CONFIDENCE_THRESHOLD etc.)
- **test(darvium)**: Add OTS-C1 cycle detection completeness test (n=2,000, p_miss=0.0 < 4.6e-4 threshold)
- **test(darvium)**: Add OTS-C2 noise injection safety test (n=500, 0 panics, 0 DAG violations)
- **refactor(darvium)**: Migrate deprecated `rand::gen/gen_range/gen_bool` to `random/random_range/random_bool`, remove unused variables (`prev_ref_cv`, `prev_pert_cv`, unused `graph` param)
