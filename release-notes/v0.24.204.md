# Release v0.24.204

## Summary
Cross-domain Event Architecture consistency verification (M1.76-23) and VirtualClock bug fix for FakeEventBus resolve/reconnect operations.

## What's Changed
- **fix**: FakeEventBus resolve/reconnect no longer incorrectly advances VirtualClock, aligning with RFC §12C.6 commit protocol
- **feat**: Add Safety Invariant debug_assert to all 4 mutation methods (publish, open, resolve, reconnect) ensuring clock never falls below committed event count
- **feat**: Add 9 new DomainProjection constructors (system_log, workflow_execution_log, knowledge_log, conversational_log, lifecycle_log, gc_log, repair_log, fusion_log, hitl_log)
- **feat**: Add 13 public make_*_event helper functions for all domains (System through Village)
- **test**: Add 7 cross-domain consistency tests (TC-1 through TC-7) covering replay completeness, kind filter accuracy, clock monotonicity, projection delivery, and JSON round-trip integrity
- **test**: Achieve cross-domain consistency score of 1.0 across all 5 metrics with n=1300 random events
- **test**: Update 5 existing tests to reflect corrected VirtualClock behavior
