# Release v0.24.167

## Summary
Implemented the HELP protocol state machine (HelpProposal/HelpOffer/HelpDecision/HelpExecution/HelpSuccess) with EventBus event publishing, completing the M1.75-3 milestone for Child Support Villages / HELP Consensus.

## What's Changed
- feat: Add HELP protocol state machine with 7-state model (Proposal → Offered → Accepted/Rejected → Executing → Succeeded/Failed) by @Toshimi Kawata
- feat: Add pure function `is_legal_help_transition()` with exhaustive transition matrix validation
- feat: Add `HelpSession` container with `transition_to()` guard implementation
- feat: Add EventBus event publishing for all HELP state transitions as `DarviumEventKind::Reciprocity`
- feat: Add `HelpProposal`, `HelpOffer`, `HelpDecision`, `HelpExecution`, `HelpSuccess`, `HelpFailure` struct definitions
- feat: Add `HelpRejectionReason` and `HelpFailureReason` enum types
- feat: Export HELP types and functions from Darvium public API (`lib.rs`)
- test: Add 13 tests including 10 unit tests (T-1..T-10) and 3 observational tests (T-O1..T-O3) with 10,000+ random transition sampling
- fix: Remove useless `usize >= 0` comparisons in EventBus test code that caused compiler warnings
- chore: Clean up unused import in village.rs test module
