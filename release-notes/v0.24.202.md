# Release v0.24.202

## Summary
Add external event subscription infrastructure (EventSubscriber, SubscriberManager, WebSocket mock) for Darvium Event Architecture.

## What's Changed
- **feat(darvium)**: Add EventSubscriber and SubscriberManager for subscription lifecycle management
- **feat(darvium)**: Add FakeWebSocketEventChannel — in-memory EventChannel implementation with VecDeque buffer
- **feat(darvium)**: Add ExternalEventClient trait and FakeExternalEventClient with fixed-seed PRNG event generation
- **feat(darvium)**: Add SubscriberSnapshot for lock-free subscriber listing
- **feat(darvium)**: Add SubscriptionId newtype (UUIDv4 wrapper)
- **feat(darvium)**: Add SubscriberStatus enum (Active, Paused, Disconnected)
- **feat(darvium)**: Add MAX_SUBSCRIBERS and FAKE_WS_CHANNEL_BUFFER_SIZE constants
- **test(darvium)**: Add 32 new tests across 7 groups (T1-T7) including observational validation
- **test(darvium)**: Verify filter accuracy (0% false positive, 0% false negative) and delivery completeness (100%)
