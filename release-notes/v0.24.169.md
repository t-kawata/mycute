# Release v0.24.169

## Summary
Implemented child-support TrainingMission specialization (M1.75-5), enabling child workflow support missions to be orchestrated on the Training Plane with proper production plane separation.

## What's Changed
- **feat(darvium):** Added `TrainingMissionKind` enum (`Production` / `ChildSupport`) with production plane guard to prevent child-support missions from executing outside safe sandbox
- **feat(darvium):** Created `ChildSupportMissionPayload` struct capturing child_id, helper_ids, village_snapshot, objective, safety_scope, and timeout
- **feat(darvium):** Implemented `spawn_child_support_mission()` function with EventBus publish integration (`TrainingEvent::MissionGenerated`)
- **feat(darvium):** Added `SafetyScope` enum (`ReadOnly`, `LimitedMutation`, `FullSandbox`) for sandbox execution scope control
- **test(darvium):** Added 14 tests including invariant, EventBus integration, and observational tests (802 total, 0 failures)
- **chore(darvium):** Updated ticket queue marking M1.75-5 complete, added constants for max helpers (10) and mission timeout (3600s)
