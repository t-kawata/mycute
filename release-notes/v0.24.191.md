# Release v0.24.191

## Summary
Implement helper quality score with benevolence (F-11) and softmax helper selection (F-12) for reciprocity-aware helper selection in the Darvium lifecycle engine.

## What's Changed
- **feat**: Add 5 new calibration constants (w_s through w_d) for F-11 helper quality score linear combination in `src/constants.rs`
- **feat**: Add `compute_helper_quality_score` — F-11 pure function computing Q = w_s·S + w_t·T + w_r·Rep + w_b·B + w_n·N - w_d·d in `src/reciprocity.rs`
- **feat**: Add `softmax_helper_selection` — F-12 pure function with log-sum-exp trick for numerical stability in `src/reciprocity.rs`
- **feat**: Add `QualityScoreBreakdown` and `SoftmaxWeight` data types in `src/event.rs`
- **feat**: Extend `ReciprocityLifecyclePolicy` with 6 new F-11 weight fields (helper_quality_w_s through helper_quality_w_d)
- **test**: Add 10 test cases (TC-1 through TC-10) covering backward compatibility, monotonicity, NaN/Inf safety (n=10⁴), softmax numerical stability (n=10⁵), tau entropy sweep (7 levels × 3 distributions)
