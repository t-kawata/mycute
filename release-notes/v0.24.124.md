# Release v0.24.124

## Summary
Add RFC §13.3 compliant `SearchBudget`, `RecursionGuard`, and `SearchBudgetSnapshot` structs with saturating increment operations, default constructors, and comprehensive boundary value tests.

## What's Changed
- **feat**: Add `SearchBudget`, `RecursionGuard`, `SearchBudgetSnapshot` with RFC §13.3 compliant field definitions
- **feat**: Implement `try_consume_iteration`, `try_consume_retrieval_call`, `try_consume_prompt_tokens` with saturation at budget limits
- **feat**: Implement `try_increment_depth` / `decrement_depth` for recursion guard with `allow_reentrant` control
- **test**: Add 16 unit tests (T1-T5 boundary value tests + OTS-1 ensemble relaxation observation)
- **refactor**: Re-export `SearchBudget`, `RecursionGuard`, `SearchBudgetSnapshot` from crate root
- **chore**: Add default budget constants (`DEFAULT_MAX_ITERATIONS`, etc.) to `constants.rs`
