# Release v0.24.91

## Summary
Fix a critical self-kill bug in `cleanup_orphan_processes()` on Windows where the process terminated itself during elevated startup.

## What's Changed
- **fix**: Replace `taskkill /F /IM` with PID-based process enumeration and per-PID killing to prevent self-termination when `current_exe()` returns short filename or different casing
- **fix**: Exclude own PID via absolute numeric comparison (`std::process::id()`) instead of unreliable filename string comparison
- **fix**: PowerShell CIM fallback now targets specific PIDs (`ProcessId={pid}`) instead of filtering by image name, eliminating self-kill risk in the fallback path
- **chore**: Add `find_all_pids_by_image_name()` helper that returns all matching PIDs via `tasklist`
- **refactor**: `#[cfg(not(windows))]` (Mac/Linux) path completely unchanged
