# Release v0.24.80

## Summary
Fixed a Windows-specific clipboard race condition where voice input flush could paste the user's previous clipboard content instead of the recognized text.

## What's Changed
- **fix**: Fixed clipboard paste timing issue on Windows in `save_paste_and_restore()` (increased paste delay from 50ms to 200ms and added clipboard content verification before restore)
- **fix**: Added same safety check to `replace_selected_text()` to prevent overwriting externally modified clipboard content
- **chore**: Created and reviewed ticket #7 with full investigation report
