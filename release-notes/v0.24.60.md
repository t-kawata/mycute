# Release v0.24.60

## Summary
Improved hotkey priority on macOS and Windows — MYCUTE now consumes hotkey events at the OS level when the toggle is active, preventing conflicts with other applications and the OS itself.

## What's Changed
- **fix**: Fixed macOS Option key detection being completely broken due to KEY_DOWN vs FLAGS_CHANGED event type mismatch. Reverted to FLAGS_CHANGED-based detection with event consumption (`return ptr::null_mut()`) to prevent OS/other apps from reacting to consumed events
- **feat**: Added WH_KEYBOARD_LL low-level keyboard hook on Windows to intercept and block MYCUTE hotkeys before they reach the OS or other applications
- **refactor**: Windows hotkey module — made internal statics/structs `pub(crate)` to share state between rdev, GetAsyncKeyState polling, and the new WH_KEYBOARD_LL hook
- **refactor**: Removed unused constants and winapi feature
- **style**: Frontend dialog and login page formatting improvements
- **chore**: Updated app icons across all platforms
