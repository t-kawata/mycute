# Release v0.24.184

## Summary
Implement ReciprocityEvent and ReciprocityEventKind data types (M1.76-1), the foundational data structures for reciprocity-aware survival and benevolence integration in the Darvium lifecycle engine.

## What's Changed
- **feat(darvium)**: Rename `ReciprocityEvent` enum to `ReciprocityEventKind` with 8 HELP protocol variants
- **feat(darvium)**: Add `ReciprocityEvent` struct (9 fields per RFC §15.10.6) with `TryFrom<DarviumEvent>` conversion
- **feat(darvium)**: Add `DarviumError::ReciprocityError(String)` variant for type-safe error handling
- **refactor(darvium)**: Rename `transition_to_event` to `transition_to_event_kind` for clarity
- **test(darvium)**: Add 7 test cases (TC-1 through TC-7) including n=1000 roundtrip integrity test
