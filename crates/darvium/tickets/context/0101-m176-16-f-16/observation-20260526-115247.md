# 観察レポート: M1.76-16 多目的較正目的関数 F-16 + 較正ハーネス

## 1. 計装の実装状況

- **計装対象**: 式 F-16 の 6 成分合成目的関数 J(θ) = λ₁·AUC + λ₂·HelpSuccessRate - λ₃·ChurnP95 - λ₄·FalseNewRate - λ₅·ReviewLoad - λ₆·InstabilityPenalty
  - SurvivalPair: AUC 計算の基本単位（benevolence_score, survived）
  - ReciprocityOperationalMetrics: 6 成分メトリクス保持構造体
  - compute_auc_benevolent_survival: Mann-Whitney U 統計量による AUC 計算
  - compute_calibration_objective: 式 F-16 合成値
  - ReciprocityCalibrationHarness: パラメータ θ 評価 + 実験ID 生成
- **実装したテストコード**: `src/calibration.rs`（mod tests 末尾、11 テスト）
- **観測した統計量**: AUC 値、J(θ) 値、6 成分値、実験ID フォーマット

## 3. 較正ループ

本チケットでは較正ハーネスの基盤構築が目的であり、実際のパラメータ sweep は M1.76-19 で実施。本観測では純粋関数の挙動検証に留まる。

## 4. 現象の解釈（日本語）

- **AUC 計算**: Mann-Whitney U 統計量による AUC 計算が正しく実装された。ランダム ranking（AUC ≈ 0.49）と完全分離 ranking（AUC = 1.0）を正しく区別できる。空スライスや全員同一結果でも panic しない（AUC = 0.5 として graceful に処理）。
- **目的関数合成**: 6 成分の線形合成が正しく実装された。負の成分は clamp により [0, 1] に収束し、NaN/Inf は一切発生しない。
- **決定論的再現性**: 同一入力に対してビットレベルで同一 J(θ) が返ることを確認。
- **実験系列管理**: `exp-{yyyymmdd}-{seq}` 形式の実験ID が正しく生成され、親実験ID の追跡も可能。

## 5. 目的関数 J(θ) の評価

- 収束速度: 該当なし（較正ループ未実施）
- 定常誤差: 該当なし
- オーバーシュート: 該当なし
- 総合評価: 較正ハーネスの基盤としての機能性は確認済み。実際の較正フェーズ（M1.76-19）で sweep 駆動による評価が必要。

## 6. 次チケットへの示唆

- M1.76-17（合成村シミュレーター）では、本ハーネスで定義した ReciprocityOperationalMetrics の各成分を実際に計算する実装が必要。
- M1.76-19（較正フェーズ）では、本ハーネスを駆動して ReciprocityLifecyclePolicy の全 calibration candidate を sweep する計画。
- ReciprocityCalibrationHarness の evaluate メソッドは現状、外部から metrics を受け取る設計。M1.76-17 の simulator と統合することで、パラメータ θ から J(θ) までの自動パイプラインが完成する。
