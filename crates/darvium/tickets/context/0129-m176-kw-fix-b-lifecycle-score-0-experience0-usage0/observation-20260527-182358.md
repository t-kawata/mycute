## 3. 較正ループ

### 反復 1
- 仮説: `EXPERIENCE_NORMALIZATION_OFFSET=1.0` により子供に baseline usage ≈ 0.095 を与え、
  lifecycle_score を非ゼロにする。gamma_child_protect を 10.0 → 5.0 に緩和しても
  lifecycle 項が機能するため、子供の GC 生存率は維持される。
- 変更定数:
  - EXPERIENCE_NORMALIZATION_OFFSET = 1.0 (新設)
  - GC_HAZARD_GAMMA_CHILD_PROTECT = 10.0 → 5.0
- 観測結果:
  - 子供 usage min = 0.095 (理論値 0.0953 と一致)
  - 子供 hazard mean = 0.060, 成人 hazard mean = 0.605
  - Child/Adult hazard ratio = 0.0995 (子供は成人の約 1/10 の hazard = 十分保護されている)
- 解釈: offset=1.0 は適切。子供の lifecycle_score は usage ベースで非ゼロ。
  gamma_child_protect=5.0 でも子供保護は過不足なく機能。

### 追加調整余地
- gamma_child_protect を 3.0 まで下げても子供 hazard は成人より低い可能性が高いが、現状の 5.0 で安全側に設定。
  Child/Adult ratio が 0.1 は子供にとって非常に有利で、生態系の健全性を維持する妥当な水準。

## 4. 現象の解釈（日本語）

経験値正規化関数 `compute_experience_normalization` に OFFSET=1.0 を導入することで、
experience=0 の子供ノードでも non-zero の usage（≈0.095）が計算されるようになった。
これにより lifecycle_score の幾何平均全体が非ゼロとなり、GC hazard の gamma_lifecycle 項が
子供に対しても機能するようになった。

具体的な効果：
- 子供の usage 最小値: 0.0 → 0.095（FIX-B1 確認）
- lifecycle_score 正規化確認: usage=0.095 で他成分 0.8 の場合 lifecycle_score ≈ 0.53（FIX-B3 確認）
- GC hazard は子供（mean=0.060）が成人（mean=0.605）より大幅に低く、子供保護が機能
- gamma_child_protect を 10.0 → 5.0 に緩和しても子供の生存確率は十分高い

これにより「gamma_child_protect=10.0 という非現実的に高い定数で強引に子供を保護する」状態から、
lifecycle_score の自然な寄与と現実的な child_protect 係数の組み合わせに移行できた。

## 5. 目的関数 J(θ) の評価

- 収束速度: 間接的影響 — lifecycle_score 正常化により j_lifecycle が正確に算出される。s_growth の精度向上。
- 定常誤差: 低下 — lifecycle_score=0 固定による j_lifecycle 過小評価が解消。
- 子供保護: 維持 — gamma_child_protect を半減しても、lifecycle 項の復活により補償。
- 総合評価: 成功。3 つの Acceptance Criteria 全て達成。
