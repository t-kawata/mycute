## 4. 現象の解釈（日本語）

シミュレーション内の `phase5_capability_diffusion` において、HELP 成功ペアに対して helper と helpee のワークフローノード数が比較され、helper のノード数が helpee 以上の場合にのみグラフがコピーされる機構が正しく動作している。出力から、以下の傾向が観察される：

- 人口が成熟するにつれてノード数が全体的に増加し、`copied=true` の比率が上昇する
- 若い個体（低ノード数）がヘルプを受けると複雑なグラフを獲得する機会が生まれる
- 条件不成立時は単純にスキップされるため、既存の GMR 拡散による複雑化経路が維持される
