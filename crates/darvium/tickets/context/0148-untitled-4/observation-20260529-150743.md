## 3. 較正ループ

### 反復 1
- 仮説: T3 で副首長が主首長に接近することを確認する（引力が斥力を上回る）
- 変更定数: `compute_repulsion_vector` に `exclude_paramount_id` パラメーター追加（主首長を斥力対象から除外）
- 観測結果: 距離が 1.386 → 1.366 に減少（約0.02 = MOVEMENT_DISTANCE 分、正規化済みベクトルが完全に主首長方向を向いている）
- 解釈: 主首長を斥力対象から除外することで、副首長の引力が斥力に打ち消されずに正しく動作するようになった。2首長系で引力+斥力が完全に相殺される問題を解決。

## 4. 現象の解釈（日本語）

ChiefRegistry の `sync_from_chiefs` によって Phase 3.8 の村首長マップからレジストリが再構築され、`get_paramount()` で主首長が特定される。主首長は移動せず不動点として機能する。

副首長は主首長への引力と、他副首長からの斥力を受ける。引力は主首長方向への正規化ベクトル、斥力は他副首長から遠ざかる方向の正規化ベクトルの総和。初期状態では副首長は引力方向に移動し、距離が減少する。

主首長を斥力対象から除外する設計判断により、2首長系でも引力が斥力に完全相殺されず、副首長が主首長に接近する力学が維持される。

非首長は最寄り首長に引き寄せられ、MIN_APPROACH_DISTANCE 以内に接近すると2番目首長に永久固定される。単一首長の場合のフォールバック（近傍ランダム点）も正常動作。

観測テスト O1 では、シミュレーション進行に伴い benevolence_score_p50 が上昇する傾向が確認された（tick=0 の 0.502 から tick=9 の 0.761）。これは Phase 3 の HELP プロトコルにより慈悲的個体が増加する通常のダイナミクスと一致する。

## 5. 目的関数 J(θ) の評価

- 収束速度: 移動距離 MOVEMENT_DISTANCE=0.02 は1tickあたり適切な移動量。10tickで距離約0.02減少。
- 定常誤差: 副首長は主首長に無限に接近せず、他副首長からの斥力と平衡状態に達する。
- オーバーシュート: 観測されず（MOVEMENT_DISTANCE < MIN_APPROACH_DISTANCE の不変条件により飛び越し防止）。
- 総合評価: 良好。移動力学は正常に動作し、全ての不変条件テストが通過。

## 6. 次チケットへの示唆

- 現在の観測テスト O2/O3 は `final_state.len()` のみ出力しており、空間分布の詳細な統計（首長間平均距離、非首長の最近接首長距離分布）は出力していない。後続チケットで `run_simulation` の戻り値に population 情報を含めるか、別途シミュレーション実行の計装を追加することが望ましい。
- 副首長間斥力の T4 テストは、全個体が同一位置から開始するため斥力がゼロとなり、実際の斥力動作を検証できていない。後続で改善可能。
