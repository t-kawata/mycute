主要な設計判断：
- Phase 0-4 の通過状況は HashMap<CalibrationPhase, PhaseStatus> で表現。これにより全 Phase PASS / 一部 FAIL の両方に対応可能。
- 要約統計量は既存の ReciprocityOperationalMetrics（calibration.rs）を再利用。
- 系列管理は既存の ExperimentLineage / LineageStore / FsLineageStore をそのまま利用。
- Markdown 出力は 9 セクション構成（標準の 8 セクション + Phase Status セクション）。
