## 4. 現象の解釈（日本語）

- 全4条件の MUST 単調性が n=1000 のランダムパラメータ sweep でも一切の違反なく成立することを確認した。
- direct_score → survival_probability の単調性は、benevolence が direct_score の単調増加関数であり、hazard が benevolence の単調非増加関数、survival が hazard の単調減少関数であることを組み合わせて成立している。
- indirect_score → GC hazard の単調非増加も同様の連鎖により成立。
- Reputation → GC hazard の単調非増加も確認。benevolence 算出時に reputation が正の重みで寄与しているため、reputation 増加は benevolence 増加を通じて hazard を減少させる。
- 条件4の helper ranking は、benevolence が helper_quality_score の一部として正の重みで算入されており、ΔB sweep [0.001, 0.5] 全域で ranking reversal が発生しないことを確認。
- 現在のデフォルトパラメータ（lifecycle=0.5, child_protection=0.5, delta_t=100）およびデフォルトポリシーでは、全条件が問題なく成立している。
