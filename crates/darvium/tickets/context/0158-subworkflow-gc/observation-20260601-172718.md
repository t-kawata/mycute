1394 passed, 0 failed （4 new tests）

## 3. 現象の解釈（日本語）
抽象化で生成された子グラフは親の PersonId を parent_id に保持する。GC 実行時、親が生存中（alive=true）の子は生存確率にかかわらず殺されない。これにより親グラフ内の SubWorkflow 参照が dangling reference になることを防止する。親が死亡した後は通常の GC 判定に戻る（子は自身の適応度で評価される）。
