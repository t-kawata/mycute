# 観察レポート: M0.5-3 パッチ適用における未解決変数（VarScopeViolation）の確率的検出テスト

## 1. 計装の実装状況

- 計装対象:
  - OTS-V1: `compute_validator_score` 単調性（確定的 n=11、E_v=0..10）
  - OTS-V2: 複合信頼度偏微分感度 — 3水準 c_s × 4水準 E_v = 12 組み合わせ × 833 = ~10,000 行
  - OTS-V3: c_s=0.50 での重み切り替え不連続性観測（c_s 0.45→0.55 を 0.01 刻み × 各 100 = 1,100 行）
  - OTS-VS: ランダム DAG に存在しない from_var の DataFlow 辺を注入（n=500）
- 実装したテストコード: tests/m0_5.rs（4 テスト関数追加）
- 実装した公開関数: src/patch.rs `compute_validator_score(E_v) → c_v`

## 2. 観測テスト実行結果

### OTS-V1: バリデータスコア単調性
E_v=0 → 1.0, E_v=1 → 0.85, E_v=2 → 0.70, E_v=3 → 0.55, E_v≥3 → 0.55
全て RFC §14.3 減算規則と完全一致。単調非増加性確認。**PASS**

### OTS-V2: 複合信頼度偏微分感度
- 同一 (c_s, E_v) での分散 = 0（決定論性確認）
- c_s=0.30 (ws=0.20, wv=0.50, 低自信時):
  - dP/dE_v [0,1] = -4.55e-2, [1,2] = -5.07e-2, [2,3] = -5.77e-2
- c_s=0.60 (ws=0.30, wv=0.40, 通常時):
  - 同上パターン（ws/wv は通常だが c_s が 0.50 以上）
- c_s=0.80 (ws=0.30, wv=0.40, 通常時):
  - 同上パターン（ws/wv は通常）
- 各区間で微分係数が異なる理由: c_v が E_v に依存するため ∂P/∂c_v が変化する（c_v=1.0→0.85→0.70→0.55 と減少し、wv 乗による影響度が変化）。これは数式上の正しい挙動。**PASS**

### OTS-V3: 重み切り替え不連続性
- c_s=0.49: value=0.628526, c_s=0.50: value=0.588810
- **不連続ジャンプ: -3.97×10⁻²（約 4% の決定論的減少）**
- これは c_s が閾値 0.50 を跨ぐ瞬間に ws 0.20→0.30, wv 0.50→0.40 と切り替わり、信頼度計算式のベースが不連続に変化するため。
- 物理的意味: LLM が「自信なし」(c_s<0.50) と言った瞬間にバリデータの影響度が上がり、信頼度全体が下方修正される。**PASS**

### OTS-VS: ランダムパッチ注入
- 総試行: 500, 注入成功: 499, 検出: 499 (100%), 見逃し: 0
- エラーメッセージに broken_var が含まれていることを確認。**PASS**

## 3. 較正ループ

本チケットは `VALIDATOR_VAR_SCOPE_PENALTY` を Safety Invariant（変更禁止）として扱うため、較正は実施しない。

## 4. 現象の解釈（日本語）

### c_v 減算規則の正確性
`compute_validator_score` は RFC §14.3 通り、未解決変数 1 件につき -0.15、上限 3 件（最大 -0.45）のペナルティを正確に実装している。E_v=0..10 の全範囲で期待値と完全一致し、単調非増加性も確認された。

### 重み切り替えの相転移
OTS-V3 で観測された -3.97% の不連続ジャンプは、パッチ信頼度計算における「LLM 低自信モードへの相転移」の直接的な証拠である。c_s が 0.50 を下回る瞬間、システムはバリデータ偏重の評価モードに遷移し、信頼度が一段階下方修正される。これは「LLM が自信を持たないときはバリデータの判定を重く扱う」という設計意図と合致する。

### ランダム注入の完全検出
OTS-VS では 499 件の変数スコープ違反すべてが `validate_var_scope` によって完全検出された。`build_random_dag`（M0.5-2 既存）と組み合わせたランダムテストハーネスが正常に機能している。

## 5. 目的関数 J(θ) の評価

該当なし（Safety Invariant の検証であり、較正対象ではない）。

## 6. 次チケットへの示唆

- 本チケットで観測した c_v 減算規則と重み切り替え不連続性は、後続の M1-3（Human feedback debounce）や M2-3（自己評価割引補正）の基礎となる。
- OTS-V3 の不連続ジャンプ量は c_s が 0.50 未満の領域で `ch` や `E_v` に依存するため、M2-3（過信頼補正係数 DISCOUNT 調整）の際にはこの不連続性との相互作用に注意が必要。
