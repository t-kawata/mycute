- 計装対象: InteractionStatus 7状態遷移可能性行列、JSON ラウンドトリップ成功率
- 実装したテストコード: src/types.rs mod tests

## 3. 較正ループ

本チケットは型定義のみであり、較正対象の定数はない。

## 4. 現象の解釈（日本語）

- 7状態遷移行列は RFC §12C の遷移則を正しく実装している。Pending から Resolved への直接遷移は禁止され、AwaitingExternal を経由する必要がある。全終端状態からの遷移は全て禁止されている。
- JSON ラウンドトリップは n = 1000 で 100% 成功しており、全7状態のシリアライズ/デシリアライズ互換性が確認された。
- 後方互換アクセサ（request(), outcome()）により、既存コードは変更なしで動作する。
