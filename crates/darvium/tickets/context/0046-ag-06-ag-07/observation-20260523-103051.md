## 3. 較正ループ

本チケットに較正対象の連続値パラメータは存在しない（バージョン比較は定性的な完全一致判定）。定数追加のみ：
- AG_HARD_GATE_DEFAULT_MODEL_VERSION = "v2.0-final"
- AG_HARD_GATE_DEFAULT_TEMPLATE_VERSION = "v2.0-final"

これらは Environment Policy Knob として分類され、環境変更時の調整が可能。

## 4. 現象の解釈（日本語）

AG-06 および AG-07 のハードゲートが完全に意図通り動作することを確認した。10 種類の異なる不一致バージョンに対して 10,000 回走査した結果、偽陽性（誤通過）は 0 件であった。また 10,000 回の一致ケースでも誤遮断は 0 件であった。

OTS-3 の階段関数マッピングでは、ハミング距離 E=0（完全一致）で P_pass=1.00、E≧1 で P_pass=0.00 という理想的なステップ特性が確認された。これは RFC が要求する「化学ポテンシャル相当の臨界距離 E_c = +1 ビット、逆温度 β → ∞ の階段関数マッピング」を完全に満たす。

大文字小文字の違い（"V2.0-FINAL" vs "v2.0-final"）や部分文字列の包含（"v2.0-final" vs "v2.0"）もピクセル単位の完全一致比較により確実にブロックされることを確認した。

## 5. 目的関数 J(θ) の評価

較正対象パラメータがないため J(θ) の本格的評価は適用外。
