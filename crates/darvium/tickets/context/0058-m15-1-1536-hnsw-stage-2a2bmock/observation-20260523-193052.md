# 観察レポート: M1.5-1 HNSW インデックス Mock

## 1. 計装の実装状況

- 計装対象: MockHnswIndex のコサイン類似度検索、ソート不変条件、三角不等式、ノイズ摂動
- 実装したテストコード: src/vector_index.rs 内 #[cfg(test)] mod tests
- 観測した統計量:
  - OTS-1: 三角不等式違反数（1536次元単位超球、n=10,000）
  - OTS-2: ソート不変条件維持率（64次元、n=1,000）
  - OTS-3: Jaccard 係数分布（64次元、noise_sigma=0.05、n=500）

## 2. 観測テスト実行結果

```

```

## 3. 較正ループ

本チケットでは新規較正パラメータを導入していないため、較正ループは実施なし。

## 4. 現象の解釈（日本語）

**OTS-1**: 1536次元単位超球上の角距離（arccos 距離）は厳密な距離計量であり、三角不等式は数学的に常に成立する。10,000 サンプル中 0 違反は実装の正当性を裏付ける。

**OTS-2**: 64次元のランダムクエリ 1,000 件に対して、検索結果は全件で類似度降順ソートが維持された。sort_by + partial_cmp によるソートが普遍的に正しく動作している。

**OTS-3**: ノイズ σ=0.05 に対する Jaccard 係数の平均 0.578 は、ノイズ強度に対して妥当な重複率を示している。分散 0.019 は安定した結果集合を示唆する。

## 5. 目的関数 J(θ) の評価

本チケットは Mock 実装であり較正対象パラメータを含まないため、J(θ) 評価は実施しない。

## 6. 次チケットへの示唆

- MockHnswIndex は M1.5-2（クロスストア一貫性）および M1.5-3（修復スキャン）のテスト基盤として使用可能
- 1536次元での三角不等式検証は高次元空間でも問題なく動作することを確認
- OTS-3 の Jaccard 係数は後続のノイズ頑健性テストのベースラインとして参照されたい
