## 3. 較正ループ

本チケットは純粋なパイプライン実装であり、constants.rs の既存定数は使用するが新たな較正対象定数は導入していない。較正ループは M1.76-16 で扱う。

## 4. 現象の解釈（日本語）

- パイプラインは決定論的であり、同一入力（イベント＋メトリクス＋ポリシー）に対して完全に同一の出力を返すことを確認した。
- イベント数が増加するにつれて、final_score の平均値が上昇する傾向が観測された（10件→50件で 0.537→0.596）。これは正イベント（HelpSucceeded 等）が負イベント（HarmfulMismatch）よりも多いサンプル構成のため。
- pipeline_independence 検証では、graph-a（正イベントのみ）と graph-b（負イベントのみ）で final_score が正しく 0.5 を挟んで対称（0.562 vs 0.438）になることを確認。
- hazard 値はすべて非負かつ有限であり、softplus の性質が正しく機能している。
