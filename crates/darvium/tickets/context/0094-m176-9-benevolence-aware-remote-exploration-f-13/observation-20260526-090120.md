# 観察レポート: M1.76-9 Benevolence-aware remote exploration (F-13)

## 1. 計装の実装状況

- 計装対象: F-13 ε_remote(c) = clip(ε₀ + a₁·need(c) - a₂·B_local_avg(c))
- 実装したテストコード: `src/reciprocity.rs` mod tests
  - 不変条件テスト: `test_f13_t1_boundary_min` 〜 `test_f13_t7_neutral` (7件)
  - 観測テスト: `test_f13_observation_response_surface` (1件)
- 観測方法: `println!` + `--nocapture` による 2D 応答曲面表出力 + 差分分布統計

## 2. 観測テスト実行結果

### 応答曲面 (a₁/a₂ ratio sweep)
a₁/a₂ = 0.5: need が低く B_local が高い領域で starvation。need≥0.8 かつ B_local≤0.3 で saturation。
a₁/a₂ = 1.0: need と B_local が釣り合い。対角線上のバランス領域が広い。
a₁/a₂ = 2.0: need 優勢。need≥0.6 では B_local に関わらず ε_max に saturation。

### 差分分布 (ε_remote - ε₀, n=10,000)
- 平均: 0.041
- 標準偏差: 0.093
- P5: -0.050, P95: 0.150
- 飽和率 (ε_max 張り付き): 36.33%
- 飢餓率 (0.0 張り付き): 45.12%

## 3. 現象の解釈（日本語）

F-13 は need と local benevolence の線形結合を ε_max で clip する単純な関数だが、2次元パラメータ空間上の応答曲面は明確に3つの領域に分かれる：

1. **starvation 領域** (ε_remote = 0.0): B_local_avg が high、child_need が low の領域。近くに優しい大人がいるので remote exploration 不要。飢餓率 45.12% と高めだが、デフォルト a₁=a₂=1.0 でランダムな (need, B_local) を入力すると半数近くが starvation に入るのは想定内 — そもそも need が低いか benevolence が高ければ remote に頼る理由がない。

2. **線形応答領域** (0 < ε_remote < ε_max): need と B_local が拮抗する遷移帯。a₁/a₂ ratio が 0.5 のときこの領域が最大で、2.0 で最小。ratio による制御が有効。

3. **saturation 領域** (ε_remote = ε_max = 0.20): child_need が十分高い領域。飽和率 36.33% と starvation よりやや低いが、a₁/a₂=2.0 では need≥0.6 で全域 saturation に入る — a₁ が効きすぎている。

## 4. 較正への示唆

- a₁ = a₂ = 1.0 (デフォルト) は対称的で自然な挙動を示す。線形応答領域が対角線周辺に広がる。
- a₁/a₂ ratio で「need 重視」と「benevolence 重視」のトレードオフを調整可能。
- 線形応答領域の幅は a₁/a₂ が 1.0 付近で最大。これにより need と benevolence の細かいバランスを捉えやすい。
- saturation 率と starvation 率は calibrate 対象の分布に依存する。実際の village 状態での need と benevolence の同時分布を測定してから a₁/a₂ を調整すると良い。
