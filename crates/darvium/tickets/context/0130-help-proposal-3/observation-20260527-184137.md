## 3. 較正ループ

### 反復 1（デフォルト設定）
- 仮説: CHILD_HELPEE_BIAS_FACTOR=2.0 により、4 方向すべての HELP ペアが発生し、双方向ペアが自然に創発する。j_reciprocity=0 が解消される。
- 変更定数: なし（デフォルト値 CHILD_HELPEE_BIAS_FACTOR=2.0 で実行）
- 観測結果:
  - 4 方向全てで HELP 発生: ✅ (aa=50, ac=292, ca=129, cc=2794)
  - 双方向ペア種: 668（全ペア種 2849 中）
  - mean_reciprocity = 0.210（j_reciprocity=0 からの大幅改善）
  - 子供 helpee 比率 94.5% > 人口比率 65.0%（バイアス有効）
- 解釈: CHILD_HELPEE_BIAS_FACTOR=2.0 は妥当。全ての不変条件が満たされ、観測テストも PASS。

### 考察
- child→child が 85.6% と支配的なのは、出生によって子供人口が成人を上回り（最終 65% vs 35%）、かつバイアスが倍加されるため。
- mean_reciprocity=0.21 は s_topology の j_reciprocity 成分を非ゼロにし、J_kw_social 天井問題を構造的に解決する。
- バイアス調整余地: 必要に応じて CHILD_HELPEE_BIAS_FACTOR を 1.5〜3.0 の範囲で調整可能。

## 4. 現象の解釈（日本語）

HELP プロトコルの成人→子供ハードフィルタを撤去し、任意 alive ノード間で helper/helpee を選択するよう修正した。これにより以下の現象が観測された：

1. **4 方向 HELP の創発**: 成人→成人（50 回）、成人→子供（292 回）、子供→成人（129 回）、子供→子供（2794 回）の全パターンが確認された。以前は成人→子供のみが発生可能だった。

2. **双方向ペアの自然発生**: 668 種類の双方向ペア（a→b と b→a の両方が存在）が確認された。これにより compute_mean_reciprocity が 0.21 まで上昇し、j_reciprocity=0 固定問題が解消した。

3. **子供 helpee バイアスの有効性**: CHILD_HELPEE_BIAS_FACTOR=2.0 により、子供が helpee となる確率（94.5%）が人口構成比（65.0%）を有意に上回った。これは「子供が支援を必要とする確率が高い」という設計意図を反映している。

4. **s_topology 天井の解除**: j_reciprocity が非ゼロになったことで、s_topology の 6 因子全てが非ゼロとなり、以前の天井 ~0.48 から改善可能な状態になった。これにより J_kw_social の上限 0.061 も引き上げられる。

5. **注意点**: child→child が支配的（85.6%）なのは、子供の GC 保護により子供人口が成人を上回り、かつバイアスが倍加するため。妥当な挙動だが、将来的にバランス調整が必要なら BIAS_FACTOR の調整で対応可能。

## 5. 目的関数 J(θ) の評価

- 収束速度: j_reciprocity=0 だったものが非ゼロになることで、kind world 較正において互恵性因子が初めて有効に寄与する。
- 定常誤差: j_reciprocity の非ゼロ化により s_topology 天井が解除され、J_kw_social の定常誤差が低下する。
- 構造的制約: RFC §41B-9 の Child(c)∧Adult(h) 条件には違反するが、これは RFC の設計矛盾（Layer 2）の暫定回避であり、RFC 改訂タスクで正規化する。
- 総合評価: 成功。C1〜C8 の全 Acceptance Criteria 達成。3 層問題のうち Layer 1（実装バグ）と Layer 3（バイアス方向）を解決。
