## 4. 現象の解釈（日本語）

決定論的リプレイシナリオにおいて、以下の現象が観測された：

1. **完全再現性の確認**: 固定 seed での 2 回実行が常に同一 trace を生成することを、
   n=100 の統計的サンプルで確認した。PRNG の初期化位置 (StdRng::seed_from_u64) と
   各 tick での呼び出し順序が決定論的である限り、bit-level の再現性が担保される。

2. **政策変更の影響範囲の局所性**: offer_policy.threshold の変更は help_sessions にのみ
   影響し、space_positions や child_growth_events には影響しないことを確認した。
   これは replay の各コンポーネント (位置更新/成熟度判定/HELP プロトコル) が
   適切に分離されていることを示す。

3. **seed 変更時の metrics 安定性**: 異なる seed でも churn P50 < 0.5, JSD P50 < 0.3,
   生存率 > 0.5 の許容範囲内に収まることを確認した。village 動態が seed 選択に
   対して頑健であることを示す。

4. **エッジケースの安全性**: 空ワークフロー・全 Child・全 Adult の各エッジケースで
   panic が発生せず、適切に空の trace または空の village を返すことを確認した。
