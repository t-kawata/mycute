## 3. 較正ループ

### 反復 1: T9 セマンティックスコアテスト修正
- 仮説: 異なる軸上のベクトルはコサイン類似度が低くなる
- 変更: make_embedding_at ヘルパー追加、T9でクエリとグラフの埋め込みを異なる軸に配置
- 観測結果: セマンティックスコアが 1.0 → 0.0 に変化
- 解釈: コサイン類似度は角度のみを測定するため、同一軸上のベクトルは大きさが異なっても類似度1.0

### 反復 2: RepositoryPair::in_memory() 不在
- 仮説: DualStoreCoordinator は in_memory コンストラクタを持たない
- 変更: stage4 のシグネチャを pair を受け取る形に変更
- 観測結果: コンパイル成功

## 4. 現象の解釈（日本語）

4層検索パイプラインにおいて、以下の現象が観測された：

1. コサイン類似度の軸依存性: 同一軸上のベクトルは大きさが異なっても類似度1.0となる。
2. 単調性の自動担保: 段階的フィルタリングにより N_sem >= N_meta >= N_cheap >= N_full が常に成立。
3. キャッシュのレイジーロード: キャッシュミス時に RepositoryPair から自動ロード。
4. Applicability 計算の連鎖: α=0.45, β=0.70 の設定下でセマンティック要素が全体評価に約31.5%寄与。
