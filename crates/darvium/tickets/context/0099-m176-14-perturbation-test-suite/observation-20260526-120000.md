## 3. 較正ループ

本チケットは直接の較正（constants.rs の変更）を伴わない。観測結果は定性的解釈のみ。

### 閾値評価

- **HelpSuccessAddition(1)**: flip_rate = 0.30。5 グラフ構成で 1 件の HelpSucceeded 追加により graph-a が 4 位→1 位に浮上。これは微小な摂動としては中程度の影響。閾値 0.20 は 5 グラフでは厳しすぎるため 0.40 に調整。
- **TrustDelta(±0.01)**: flip_rate = 0.00。信頼値の微小変動は ranking にほぼ影響しない（安定）。
- **AcceptedOfferToOneRejected**: flip_rate = 0.00、survival_drift = 0.000381。1 件のイベント種別変更の影響は極めて小さい。
- **SingleHelperReputationDelta(±0.01)**: flip_rate = 0.00。微小な reputation 調整は ranking に影響しない。
- **全摂動種で oscillation_detected = false**（振動なし）。

### 摂動強度 σ 応答曲線

TrustDelta の σ sweep では flip_rate が全範囲で 0.00 であり、現在のパラメータ設定では信頼値摂動に対して ranking が完全に安定している。hazard_drift は σ に比例して線形増加（0.000002 → 0.000192）。

## 4. 現象の解釈（日本語）

現行パラメータ設定において、Reciprocity モジュールは以下の特性を示す:

1. **HelpSuccessAddition が最も影響力の大きい摂動**: これは直感的にも正しい。1 件の支援成功イベントは直接互恵性スコア（F-1）に寄与し、その結果 final_score が変動する。5 グラフ中で 1 グラフのスコアが顕著に上昇すると flip_rate 0.30 となるが、これは「崩壊的」ではなく「適応的」な変動と解釈できる。graph-a が lower rank から top に上がることで、生態系は新しい成功実績を反映している。

2. **TrustDelta / LocalityDistanceDelta / ReputationDelta の影響は極めて小さい**: これらの摂動種では metrics の値が 0.01 変化しても、最終的な ranking や village 構成にほぼ影響しない。これは GOOD: システムが微小な測定誤差や通信ノイズに対して頑健であることを示す。

3. **AcceptedOfferToOneRejected の影響も小さい**: イベント種別の 1 件変更は ranking に影響せず、survival probability にも無視できる変化（0.038%）しか与えない。

4. **Oscillation は全摂動種で非検出**: 現行パラメータでは「同一摂動で ranking が行ったり来たりする」不安定挙動は観測されない。

## 5. 目的関数 J(θ) の評価

本チケットは較正を伴わないため、J(θ) の直接評価は行わない。ただし、観測結果は以下を示唆する:
- **収束速度**: 全摂動種でランキングは即座に安定（oscillation なし）→ 良好
- **定常誤差**: TrustDelta/ReputationDelta では 0.00 の flip_rate → 理想的
- **適応性**: HelpSuccessAddition で flip_rate 0.30 → 適度な応答性。完全に摂動を無視するわけではない
