# M1.76-KW-REAL-P6: 計装インターフェース更新

## Summary

RFC §15.9.2 の 5 因子乗算結合モデルへの改訂に伴い、KindWorldMetricsInput に 8 フィールドを追加し、compute_kind_world_objective を旧 6 成分加重和から新 5 因子乗算結合に書き換える。collect_final_metrics の引数型を ReciprocitySimulationResult → SimulationContext に変更する。新旧両方の J_kw を計算し比較する互換性診断関数を実装する。

## Background

本チケットは M1.76-KW-REAL シリーズ 6 チケットの最終（第 6 弾）であり、P4（6 フェーズループ）完了後に実装する。P4 で導入した SimulationContext を既存の計装関数が受け取れるようインターフェースを更新する。

RFC §15.9.2 で定義された 5 因子乗算結合モデルでは、加重和（Σαᵢxᵢ）ではある因子の劣化を別の因子がマスクできる問題に対処するため、全因子が J_kw に multiplicative に寄与する乗算結合を採用する。1 因子でも 0 に近づけば J_kw 全体が強く減衰するため、全 10 セクション・57 機構の捕捉が数学的に強制される。

### チケット系列の位置づけ

KW-REAL シリーズは以下の 6 チケットで構成される：
1. ✅ P1: SimulationContext 基盤
2. ✅ P5: ライフサイクル・成熟機構
3. ✅ P4: 6 フェーズシミュレーションループ
4. ✅ P2: GMR 抽象化層
5. ✅ P3: ワークフロー実行抽象化
6. 🔴 **P6: 計装インターフェース更新（本チケット）**

P6 は P4 完了後に実装する（MUST NOT）。P4 で SimulationContext に追加される全フィールドを metrics に含める必要があるため、P4 より先に実装してはならない。P4 は既に reviewed 済みのため依存関係は充足済み。

## Scope

### 1. KindWorldMetricsInput に 8 フィールド追加（9 → 17 フィールド）

現在の 9 フィールドに以下 8 フィールドを追加：
- `mean_lifecycle_score: f64` [0,1] — 全個人の LifecycleScore $L(G)$ の算術平均
- `child_survival_rate: f64` [0,1] — 子供（経験不足個人）の生存割合
- `mean_freshness: f64` [0,1] — 全個人の BlendedFreshness $F_{time}$ の算術平均
- `mean_benevolence_aggregate: f64` [0,1] — 全個人の慈悲総和 $B_i$ の算術平均
- `mean_reciprocity_score: f64` [0,1] — 全個人の $(R^{dir} + R^{ind}) / 2$ の平均
- `help_success_rate: f64` [0,1] — 成功 HELP / 全 HELP セッション数
- `trust_inheritance_fidelity: f64` [0,1] — 世代間信頼継承忠実度
- `execution_success_rate: f64` [0,1] — 成功実行 step / 全実行 step 数

`KindWorldMetricsInput::zero()` に新 8 フィールドの初期化を追加（全 0.0）。

### 2. compute_kind_world_objective を 5 因子乗算結合に書き換え

**旧モデル（6 成分加重和）:**
```
J_kw = α₁·J_pop + α₂·J_cov + α₃·J_reuse + α₄·J_cost + α₅·J_village + α₆·J_penalty
```

**新モデル（5 因子乗算結合 RFC §15.9.2）:**
```
J_kw = S_viab × S_capa × S_coop × S_effi × S_fair
```

各因子の定義:

| 因子 | 成分 | 算術平均対象 |
|------|------|-------------|
| S_viab | 4 成分 | (J_pop + J_lifecycle + J_child_survival + J_freshness) / 4 |
| S_capa | 3 成分 | (J_cov + J_diffusion + J_reuse) / 3 |
| S_coop | 4 成分 | (J_benevolence + J_reciprocity + J_help + J_trust) / 4 |
| S_effi | 2 成分 | (J_cost + J_execution) / 2 |
| S_fair | 1 成分 | 1.0 - J_penalty |

**Kind World 達成条件:**
```
is_kind_world = (J_kw > 0.8) && (min(S_viab, S_capa, S_coop, S_effi, S_fair) > 0.6)
```

旧 8 二値フラグは較正条件から排除し、`legacy_flags: [bool; 8]` として diagnostics に格下げ。

### 3. KindWorldAssessment に 5 因子 + 14 下位成分を追加

RFC 定義に従い、KindWorldAssessment を拡張:
```rust
pub struct KindWorldAssessment {
    pub is_kind_world: bool,   // J_kw > 0.8 && min(S_i) > 0.6
    pub j_kw: f64,             // S_viab × S_capa × S_coop × S_effi × S_fair
    // 5 因子値
    pub s_viability: f64,
    pub s_capability: f64,
    pub s_cooperation: f64,
    pub s_efficiency: f64,
    pub s_fairness: f64,
    // 14 下位成分 (diagnostics)
    pub j_pop: f64,
    pub j_lifecycle: f64,
    pub j_child_survival: f64,
    pub j_freshness: f64,
    pub j_cov: f64,
    pub j_diffusion: f64,
    pub j_reuse: f64,
    pub j_benevolence: f64,
    pub j_reciprocity: f64,
    pub j_help: f64,
    pub j_trust: f64,
    pub j_cost: f64,
    pub j_execution: f64,
    pub j_penalty: f64,
    // 旧 8 二値フラグ (diagnostics)
    pub legacy_flags: [bool; 8],
}
```

### 4. collect_final_metrics の引数型変更

`collect_final_metrics` の引数型を `ReciprocitySimulationResult` → `SimulationContext` に変更。
内部で以下を抽出：
- 人口 → memoized_graph.graph.node_count()
- 各村サイズ → village_assignments から集計
- 能力カバレッジ → positions の分散から計算
- HELP 統計 → help_sessions 履歴から集計
- GC 統計 → GC 状態分布から集計
- 新 8 指標 → SimulationContext の各フィールドから収集

### 5. EcosystemGrowthObserver / VillageInteractionObserver に SimulationContext 対応メソッド追加

既存の observe メソッドは削除せず、新規メソッドを追加する形で対応：
- `EcosystemGrowthObserver::observe_from_context(ctx: &SimulationContext) -> EcosystemGrowthMetrics`
- `VillageInteractionObserver::observe_from_context(ctx: &SimulationContext) -> VillageInteractionMetrics`
