# M-2-3: 決定論的空リターン用 Mock クライアントの実装

## Summary

`RetrievalPrimitive` トレイトを実装し、常に空の `CandidateSet` を返す `MockEmptyRetrievalPrimitive` と、
常に `DarviumError::RetrievalTimeout` を返す `MockErrorRetrievalPrimitive` の 2 種の Mock 構造体を実装する。
これらはどのようなクエリが入力されても 100% 決定論的に指定の応答を即座に返すコントラクトを持ち、
後続の状態機械テスト（M-1.5〜M-1）で FakeExecutor の構成要素として使用される。

- **関連 RFC**: §13.4（RetrievalPrimitive pure retrieval contract）
- **対応チケット**: M-2-3（Darvium-Tickets-v2.3.md L156-L165）

## Background

RetrievalPrimitive は SearchWorkflow と具象検索実装の間の純粋抽象境界を定義するトレイトである。
M-2-1 でトレイトの型シグネチャが確定した現在、後続のフェーズ（M-1.5 状態機械、M-1 ポリシー評価）では
検索結果が「常に空」または「常にエラー」という極端な条件下での SearchWorkflow の挙動検証が必要となる。

現状、テスト用の `DummyRetrievalPrimitive`（常に空を返す）は `src/types.rs` の `#[cfg(test)] mod tests` 内に
非公開で存在するのみであり、以下の問題がある：

1. **外部テストからの再利用不可**: `#[cfg(test)]` モジュール内にあり、`tests/` ディレクトリの統合テストや
   後続チケットのテストから参照できない
2. **エラーケース未カバー**: タイムアウトエラーを返す実装が存在しない
3. **計装プローブ不在**: 決定論性の観測ベース検証に必要な仮想命令カウンタが組み込まれていない
4. **Mock としての明示性不足**: テストダブルであることが型名から明確でない

このチケットでは、これらの問題を解決する公開 Mock 構造体を `src/` 配下に実装する。

## Scope

1. **`MockEmptyRetrievalPrimitive` 構造体の実装**: 常に空の `CandidateSet`（`candidates: Vec::new()`、
   `retrieval_calls_used: 0`）を返す
2. **`MockErrorRetrievalPrimitive` 構造体の実装**: 常に `DarviumError::RetrievalTimeout` を返す
3. **`MockRetrievalPrimitive` 列挙型の実装**: 上記 2 種を統合する列挙型ラッパー（`Empty` / `Error` バリアント）
4. **仮想命令カウンタ計装**: 内部に `invocation_count: AtomicU64` を保持し、`search_workflows` 呼び出しごとに
   インクリメントする計装プローブ
5. **決定論性の観測テスト**: クエリのシャノンエントロピーを可変させた際の消費命令ステップ数分散 σ² が
   ゼロであることの検証
6. **Mock 構造体の公開**: `src/lib.rs` からの `pub mod mock;` によるモジュール公開

## Non-scope

- 非決定論的挙動を持つ Mock（乱数に基づく応答など） — チケット M-0.5 で扱う
- `FakeLlmClient` / `FakeEmbeddingProvider` — 別チケット
- 状態機械との統合テスト — チケット M-1.5-1 以降
- `SearchBudget` / `RecursionGuard` との結合 — チケット M-1-2 / M-1-3
- `proptest` を使用したプロパティベーステスト — チケット M0.5

### 純粋検索契約（RFC §13.4）

RFC §13.4 は `RetrievalPrimitive` に以下の契約を課している:
- 最終意思決定権を持たない（decision-free）
- 検索結果は候補の提示に留まり、採用判断は行わない
- 副作用を一切発生させない（pure retrieval contract）

Mock クライアントはこの契約を最も厳密に遵守する実装であり、以下を保証する:
- どのような入力に対しても同じ出力を返す（参照透明性）
- 副作用ゼロ（メモリアロケーション以外の外部状態変更なし）
- 返答遅延ゼロ（即座の同期的リターン）

## 計装方法・観測対象

### 計装方法

#### 仮想命令ステップ数計装

物理時間ではなく、コード内の以下のインストルメンテーションカウンタが消費する仮想命令ステップ数を計測する:

1. **`invocation_count: AtomicU64`**: `search_workflows` の呼び出し回数
2. **アロケーションカウンタ**: `Vec::new()` 等の内部アロケーションによる確保バイト数

これらのカウンタを用いて、入力クエリのシャノンエントロピーと出力命令ステップ数の間の完全な独立を検証する。

#### Kolmogorov 複雑度の不変性

入力クエリ空間から出力空間への写像 f: Q → R において、
Kolmogorov 複雑度 K(f(q)) が q に依存せず一定であることを検証する。
具体的には、任意の q₁, q₂ に対して K(f(q₁)) = K(f(q₂)) が成立することを、
出力バイト列の圧縮率の同一性を通じて間接的に観測する。

### 観測対象

- `invocation_count` の呼び出しごとの変化（常に +1 の単調増加）
- クエリのシャノンエントロピーを H(Q) ∈ [0, 8] ビットで可変させた際の、
  消費命令ステップ数 S_inst の分散 σ²(S_inst) = 0（完全同型性）
- 出力バイト列の圧縮率の一致（Kolmogorov 複雑度不変性のプロキシ観測）
- 空返却 Mock とエラー返却 Mock 間のメモリアロケーション特性の差異

### 較正計画

本チケットは Mock 実装であり、調整可能な較正定数を含まない。
`invocation_count` の初期値（常に 0）は Safety Invariant とみなす。

### 観測テスト (Observational Tests)

**OTS-1: クエリエントロピー vs 命令ステップ分散 (σ²(S_inst) = 0)**

- シード固定 PRNG で 8,192 個の多様な `QueryRepresentation` を生成
  - `mission_text`: シャノンエントロピー H ∈ [0, 8] ビットの範囲で可変
  - `task_embedding`: ランダム次元数 + ランダム値
  - `query_type`, `freshness_requirement` など列挙型フィールドもランダム化
- 各クエリで `search_workflows` を呼び出し、その前後での `invocation_count` 差分を計測
- 消費命令ステップ数 S_inst（= カウンタ差分）の分散 σ² を計算し、ゼロであることを検証
- 出力形式: JSON（`{"min": N, "max": N, "mean": N, "variance": 0.0, "sample_size": 8192}`）

**OTS-2: Kolmogorov 複雑度不変性の観測**

- 8,192 個のクエリに対する `CandidateSet` 出力をバイト列として収集
- 各出力バイト列の gzip 圧縮率（圧縮後サイズ / 圧縮前サイズ）を計測
- 全出力の圧縮率が等しいことを確認（Kolmogorov 複雑度一定のプロキシ検証）
- 特に空 Mock の場合、全ての出力が同一バイト列となるため圧縮率が完全一致する

**OTS-3: 関数呼び出しの実時間不変性**

- 同一 Mock インスタンスに対する 10,000 回の連続呼び出しを計測
- 各呼び出しの経過時間（`std::time::Instant` による差分）を記録
- 100 回目と 10,000 回目の呼び出し時間に統計的有意差がないことを確認
  （キャッシュウォームアップ等の影響を受けず常に即座に返る）

## 実装詳細

### 新規ファイル: `src/mock.rs`

```rust
/// 決定論的空リターン用 MockRetrievalPrimitive (RFC §13.4 pure retrieval contract)。
///
/// どのようなクエリが入力されても 100% 決定論的に指定の応答を即座に返す。
/// 内部に invocation_count を持ち、呼び出し回数を計測する。
use std::sync::atomic::{AtomicU64, Ordering};

use crate::error::DarviumError;
use crate::types::{CandidateSet, QueryRepresentation, RetrievalPolicy, RetrievalPrimitive};

/// 常に空の CandidateSet を返す Mock。
#[derive(Debug)]
pub struct MockEmptyRetrievalPrimitive {
    invocation_count: AtomicU64,
}

impl MockEmptyRetrievalPrimitive {
    pub fn new() -> Self {
        Self {
            invocation_count: AtomicU64::new(0),
        }
    }

    /// 現在の呼び出し回数を取得する。
    pub fn invocation_count(&self) -> u64 {
        self.invocation_count.load(Ordering::Relaxed)
    }
}

impl Default for MockEmptyRetrievalPrimitive {
    fn default() -> Self {
        Self::new()
    }
}

impl RetrievalPrimitive for MockEmptyRetrievalPrimitive {
    fn search_workflows(
        &self,
        _query: &QueryRepresentation,
        _policy: &RetrievalPolicy,
    ) -> Result<CandidateSet, DarviumError> {
        self.invocation_count.fetch_add(1, Ordering::Relaxed);
        Ok(CandidateSet::empty())
    }
}

/// 常に RetrievalTimeout エラーを返す Mock。
#[derive(Debug)]
pub struct MockErrorRetrievalPrimitive {
    invocation_count: AtomicU64,
}

impl MockErrorRetrievalPrimitive {
    pub fn new() -> Self {
        Self {
            invocation_count: AtomicU64::new(0),
        }
    }

    /// 現在の呼び出し回数を取得する。
    pub fn invocation_count(&self) -> u64 {
        self.invocation_count.load(Ordering::Relaxed)
    }
}

impl Default for MockErrorRetrievalPrimitive {
    fn default() -> Self {
        Self::new()
    }
}

impl RetrievalPrimitive for MockErrorRetrievalPrimitive {
    fn search_workflows(
        &self,
        _query: &QueryRepresentation,
        _policy: &RetrievalPolicy,
    ) -> Result<CandidateSet, DarviumError> {
        self.invocation_count.fetch_add(1, Ordering::Relaxed);
        Err(DarviumError::RetrievalTimeout)
    }
}

/// 統合 Mock 列挙型。
///
/// テストシナリオに応じて Empty / Error を動的に切り替えたい場合に使用する。
#[derive(Debug)]
pub enum MockRetrievalPrimitive {
    Empty(MockEmptyRetrievalPrimitive),
    Error(MockErrorRetrievalPrimitive),
}

impl RetrievalPrimitive for MockRetrievalPrimitive {
    fn search_workflows(
        &self,
        query: &QueryRepresentation,
        policy: &RetrievalPolicy,
    ) -> Result<CandidateSet, DarviumError> {
        match self {
            MockRetrievalPrimitive::Empty(m) => m.search_workflows(query, policy),
            MockRetrievalPrimitive::Error(m) => m.search_workflows(query, policy),
        }
    }
}
```

- Mock 構造体の名前は「何をする Mock か」が型名だけで判別できるようにする
