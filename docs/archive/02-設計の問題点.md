### 1. tahoe_implementation_analysis.md

```markdown
# Tahoe Voice Implementation - 実装可能性検証と改善案

作成日: 2026-01-09  
分析対象: tahoe_voice_implementation.md  
評価基準: 「本当に動くかどうか」の実装可能性（設計の綺麗さや保守性は評価対象外）

## Executive Summary

設計書の基本構想は良好だが、以下の致命的な問題が複数存在し、このままでは期待通りには動かない。

| # | 問題 | 重要度 | 動作への影響 |
|---|------|--------|------------|
| 1 | SpeechAnalyzer/SpeechRecognizer API 仕様の未確定・未検証 | 致命的 | STT が開始できない／落ちる |
| 2 | cpal → macOS Speech への音声データ受け渡しが不明瞭 | 致命的 | マイク入力が STT に届かない |
| 3 | CGEvent ベースのキーボード入力と Accessibility 権限 | 致命的 | テキキーボード注入が 100% 失敗 |
| 4 | NSWindow/NSTextView を非メインスレッドから操作 | 重大 | 不定期クラッシュ・UIが出ない |
| 5 | Objective‑C オブジェクトのメモリ管理（retain/release） | 重大 | リーク or use-after-free でクラッシュ |
| 6 | LLM クライアントの API 仕様決め打ち | 重要 | LLM 補正が動かないが、他機能は動く |

本分析では「どうすればとりあえず動くか」にのみフォーカスし、実装の美しさ・抽象度・保守性などは意図的に無視する。

## 問題1: SpeechAnalyzer / SpeechRecognizer API 未確定

### 現状の記述

設計書では、macOS “Tahoe 26” で新登場したとされる `SpeechAnalyzer` クラスと、既存の `SpeechRecognizer` クラスを前提に書かれている。

```rust
pub fn new(locale: &str) -> Result<Self, String> {
    unsafe {
        // Tahoe 新APIを試す
        if let Some(cls) = Self::get_speech_analyzer_class() {
            return Self::init_with_analyzer(cls, locale);
        }

        // フォールバック: 従来の SpeechRecognizer
        let cls = class!(SpeechRecognizer);
        if cls.is_null() {
            return Err("Neither SpeechAnalyzer nor SpeechRecognizer available".to_string());
        }

        Self::init_with_recognizer(cls, locale)
    }
}
```

しかし：

- `SpeechAnalyzer` が本当に存在するか・シンボル名が正しいか不明
- `SpeechRecognizer` に対する `startListening`／`setSupportsOnDeviceRecognition:` などの selector が現実の API と一致している保証がない
- デリゲート／コールバックの登録方法（partial/final result を Rust 側に渡す仕組み）が未定義

### 実際に起こり得る失敗パターン

- `class!(SpeechAnalyzer)` でコンパイルは通るが、実行時に NULL クラスになる
- `objc_getClass("SpeechRecognizer")` 自体は成功するが、`startListening` などが存在しない（シグネチャ違い）
- partial result イベントを受け取る delegate が正しく設定されず、結果が Rust に届かない

### 「動かす」ための現実的な方針

1. **Tahoe 固有の `SpeechAnalyzer` は一旦無視する**  
   - 実在しない可能性もあるため、まずは macOS 13+ の `SFSpeechRecognizer` 系 API に対応するラッパとして `SpeechRecognizer` に固定し、クラス名での分岐だけ残す
2. **クラス存在チェックを runtime ベースにする**  
   - `objc_getClass("SpeechAnalyzer")` が NULL の場合はスキップ
   - それでも NULL なら致命的エラーとして早期 return（ログを出して終了）
3. **最初は「結果が1回出るだけ」でもよい**  
   - partial/final の区別やストリーミング精度は後回し
   - まずは短い音声を流して 1 回 transcribe できることをゴールにする

## 問題2: cpal → SpeechRecognizer への音声パスが空白

### 現状の記述

`stt/audio_engine.rs`:

- `cpal` の `build_input_stream` でマイクから PCM を受け取る
- しかし、そのバッファをどう `SpeechRecognizer` 側に渡すかは「コメントのみ」で実装されていない

典型的な疑問点:

- `SpeechRecognizer` は「自前の AVAudioEngine を持つスタイル」なのか、「外部から PCM を渡すスタイル」なのか、どちら前提なのか不明
- もし Apple の `SFSpeechRecognizer` 型を想定しているなら、多くの場合 AVAudioEngine と組み合わせて「内部で」マイクをハンドルするため、`cpal` を挟む必要はない

### 想定される失敗

- `cpal` では音は取れているが、Speech フレームワークは別のデバイスを使っており、認識が常に無音扱いになる
- サンプリングレート 16kHz を強制しているが、デバイス側が非対応で `No suitable input config found` が頻発する

### 「動かすため」の最小方針

- **戦略A（単純）：macOS側に完全に任せる**
  - `cpal` をやめて、Objective‑C 側で AVAudioEngine + Speech フレームワークを組み、そのラッパだけ Rust から叩く
  - Rust は「start/stop とテキスト受信」だけ行う
- **戦略B（どうしても cpal を使いたい場合）**
  - `cpal` から i16 mono PCM を受け取り、リングバッファに詰める
  - 別スレッドで一定フレームごとに `AVAudioPCMBuffer` 相当を作り、`SpeechAnalyzer` の `processAudioBuffer:completion:` に渡す（ただしこれは API 仕様が不明なので博打）

**結論**: 「まず動かす」だけなら A のほうが圧倒的に成功確率が高い。設計書の cpal 部分は一旦凍結し、Apple 推奨ルートで組み直すのが現実的。

## 問題3: キーボード入力と Accessibility 権限

### 現状の記述

`input/keyboard.rs` は `CGEventCreateKeyboardEvent` と `CGEventPost` を使ってテキストを注入する設計になっているが：

- macOS では、この操作には「アクセシビリティ」の許可が必須
- 許可が無い場合でも、エラーではなく「何も起きない」ことが多い（= デバッグがつらい）
- 設計書では権限周りのフローがほぼノータッチ

### よくある失敗パターン

- 実装そのものは正しくても、System Settings → Privacy & Security → Accessibility にアプリが追加されておらず、全く入力されない
- ユーザー／開発者が「なぜ動かないのか」をログから判別できない（CGEventPost は沈黙する）

### 「動かす」ために最低限必要なもの

1. 起動直後に `AXIsProcessTrusted()` 相当を呼び出し、「権限がないなら標準エラーに日本語でデカく出す」
2. それでも続行するかどうかは問わず、とにかく「権限がない状態」の可能性をログで可視化する
3. README レベルに「Accessibility にこのバイナリ（もしくは Terminal.app）を追加せよ」を明記

## 問題4: UI (NSWindow/NSTextView) を非メインスレッドから触っている

設計書の Rust 側 UI コード（`ui/popup.rs`）は:

- `tokio` の async 文脈からそのまま `NSWindow` や `NSTextView` のメソッドを呼んでいる
- macOS AppKit は UI 操作をメインスレッドに限定している（原則）

### 想定される症状

- 起動はするが、ポップアップが一切出ない
- 特定環境でのみクラッシュ（スレッド境界の UB）
- 将来的な macOS バージョンで突然壊れる

### 「動かす」ための最低限の措置

- 「UI 操作用の専用スレッド（実質メインスレッド）」にコマンドを投げる MPSC チャネルを作る
- Rust 側からは `append_text("...")` などを送るだけで、実際の NSTextView への反映は `spawn_blocking` か専用ランループスレッドに任せる

## 問題5: Objective‑C FFI メモリ管理

設計書は概ね `objc2::rc::Id<T, Shared>` を使っており方針はよいが、以下のような危うい箇所がある：

```rust
let recognizer: *mut Object = msg_send![cls, new];
if recognizer.is_null() {
    return Err("Failed to create SpeechRecognizer".to_string());
}
let recognizer = Id::retain(recognizer).ok_or("Failed to retain SpeechRecognizer")?;
```

典型的な罠：

- `new` が既に retain + autorelease 済みかどうかの扱い
- `alloc` → `init` パターンと `new` を混在させた際の retain カウント
- `Drop` 実装で `stopListening` のみ呼び、release を二重に呼んでしまうケース

**結論**: 「最低限 crash しない」ことだけを目標にするなら

- 全て `alloc` → `init` に統一し、`Id::retain` で所有権を Rust 側に移す
- 自前で `release` は呼ばず、`Id` に任せる
- Drop では「メソッド呼び出しのみ」にし、ポインタの解放は一切しない

---

## 問題6: LLM クライアントの API 決め打ち

`llm/client.rs` は OpenAI Chat Completions API をほぼ決め打ちしているが：

- `base_url` に `/v1` が付いている／いない問題
- OpenAI 互換を謳う別ベンダ（Ollama, vllm, etc.）だと `choices[0].message.content` 形式でない場合もある
- エラー時のレスポンスを `status` だけ見て汎用の `"API error"` しか返していない

これは致命傷ではないが、「LLM連携が動かない」という問い合わせを量産する危険がある。  
ただし、STT・UI・キーボード注入とは独立しているため、「最初の動くバージョン」では LLM をオフにしてもよい。

## この設計で「本当に動くか」の判定

- **そのまま実装した場合**  
  → 高確率で「ビルドは通るが、録音も入力も何も起きない」状態になる

- **以下を守れば、現実的に動かせる可能性が高い：**
  1. `SpeechAnalyzer` は一旦無視し、macOS 13+ の `SpeechRecognizer` だけをターゲットにする
  2. マイク入力は Apple の AVAudioEngine + Speech フレームワークに丸投げし、`cpal` や独自 PCM ループは一旦使わない
  3. 起動時に Accessibility 権限の有無を必ずチェックし、なければ明示的にエラーメッセージで終了する
  4. UI 操作は専用スレッド（もしくは `spawn_blocking`）に隔離し、async から直接 AppKit を触らない
  5. Objective‑C オブジェクトの所有権は `Id<T, Shared>` に全て任せる

以降の `tahoe_improved_implementation` では、この「動かすための現実解」を前提にした具体的なコード案を出している。

## STT ラッパ（src/stt/speech_recognizer.rs）

```rust
use objc2::{class, msg_send, sel, sel_impl};
use objc2::rc::{Id, Shared};
use objc2::runtime::Object;
use objc2_foundation::{NSString, NSLocale};
use tokio::sync::mpsc;
use std::sync::{Arc, Mutex};

#[derive(Debug, Clone)]
pub enum SttEvent {
    PartialResult(String),
    FinalResult(String),
    Error(String),
}

pub struct SpeechRecognizer {
    recognizer: Id<Object, Shared>,
    locale: Id<NSLocale, Shared>,
    event_tx: Arc<Mutex<Option<mpsc::Sender<SttEvent>>>>,
}

impl SpeechRecognizer {
    pub fn new(locale: &str) -> Result<Self, String> {
        unsafe {
            // まず Tahoe 用 SpeechAnalyzer を試す（あれば使う）
            if let Some(cls) = Self::get_class("SpeechAnalyzer") {
                return Self::init_with_class(cls, locale);
            }
            // なければ従来の SpeechRecognizer
            let cls = class!(SpeechRecognizer);
            if cls.is_null() {
                return Err("SpeechRecognizer class not found".to_string());
            }
            Self::init_with_class(cls, locale)
        }
    }

    unsafe fn get_class(name: &str) -> Option<&'static objc2::runtime::Class> {
        let cstr = std::ffi::CString::new(name).unwrap();
        objc2::runtime::objc_getClass(cstr.as_ptr()).as_ref()
    }

    unsafe fn init_with_class(
        cls: &objc2::runtime::Class,
        locale: &str,
    ) -> Result<Self, String> {
        let ptr: *mut Object = msg_send![cls, new];
        if ptr.is_null() {
            return Err("Failed to create recognizer instance".to_string());
        }
        let recognizer = Id::retain(ptr).ok_or("Failed to retain recognizer")?;

        let loc_id = NSString::from_str(locale);
        let loc = NSLocale::alloc().initWithLocaleIdentifier(&loc_id);

        let _: () = msg_send![&*recognizer, setLocale: &*loc];

        // 可能なら on-device モードを有効化（macOS 13+）
        let _: () = msg_send![&*recognizer, setSupportsOnDeviceRecognition: true];

        Ok(SpeechRecognizer {
            recognizer,
            locale: loc,
            event_tx: Arc::new(Mutex::new(None)),
        })
    }

    pub async fn start(&mut self) -> Result<mpsc::Receiver<SttEvent>, String> {
        let (tx, rx) = mpsc::channel(100);
        *self.event_tx.lock().unwrap() = Some(tx);
        unsafe {
            let _: () = msg_send![&*self.recognizer, startListening];
        }
        Ok(rx)
    }

    pub fn stop(&mut self) {

    // ここは Objective‑C 側から呼ばれるコールバック用に想定
    pub(crate) fn handle_partial_result(&self, text: &str) {
        if let Some(tx) = self.event_tx.lock().unwrap().as_ref() {
            let _ = tx.try_send(SttEvent::PartialResult(text.to_string()));
        }
    }

    pub(crate) fn handle_final_result(&self, text: &str) {
        if let Some(tx) = self.event_tx.lock().unwrap().as_ref() {
            let _ = tx.try_send(SttEvent::FinalResult(text.to_string()));
        }
    }

    pub(crate) fn handle_error(&self, err: &str) {
        if let Some(tx) = self.event_tx.lock().unwrap().as_ref() {
            let _ = tx.try_send(SttEvent::Error(err.to_string()));
        }
    }
}

impl Drop for SpeechRecognizer {
    fn drop(&mut self) {
        self.stop();
    }
}
```

※ 実際には Objective‑C 側で delegate を生やして Rust の `handle_partial_result` などを呼ぶ必要があるが、「期待通り動作するか」という観点だと **まずは FinalResult 1 回だけでも返るパス**を優先して実装するのが現実的。

## キーボード注入（src/input/keyboard.rs）

```rust
use objc2::{class, msg_send, sel, sel_impl};
use objc2_core_graphics::{CGEventCreateKeyboardEvent, CGEventPost, CGKeyCode};
use tokio::time::{sleep, Duration};

pub struct KeyboardInjector;

impl KeyboardInjector {
    pub fn check_accessibility_permission() -> Result<(), String> {
        unsafe {
            let trusted: bool = msg_send![class!(AXUIElement), isProcessTrusted];
            if trusted {
                Ok(())
            } else {
                Err("このアプリにはアクセシビリティ権限がありません。System Settings > Privacy & Security > Accessibility で追加してください。".into())
            }
        }
    }

    pub async fn type_text(text: &str) -> Result<(), String> {
        for ch in text.chars() {
            Self::type_char(ch).await?;
            sleep(Duration::from_millis(5)).await;
        }
        Ok(())
    }

    async fn type_char(ch: char) -> Result<(), String> {
        let keycode = Self::char_to_keycode(ch)?;
        let shift = ch.is_uppercase();
        unsafe {
            if shift {
                Self::send_key_event(56, true)?; // Shift down
                sleep(Duration::from_millis(2)).await;
            }
            Self::send_key_event(keycode, true)?;  // key down
            sleep(Duration::from_millis(1)).await;
            Self::send_key_event(keycode, false)?; // key up
            if shift {
                sleep(Duration::from_millis(1)).await;
                Self::send_key_event(56, false)?; // Shift up
            }
        }
        Ok(())
    }

    unsafe fn send_key_event(keycode: CGKeyCode, down: bool) -> Result<(), String> {
        let event = CGEventCreateKeyboardEvent(std::ptr::null_mut(), keycode, down);
        if event.is_null() {
            return Err(format!("Failed to create event for keycode {}", keycode));
        }
        CGEventPost(1, event); // kCGHIDEventTap
        Ok(())
    }

    fn char_to_keycode(ch: char) -> Result<CGKeyCode, String> {
        let code = match ch {
            'a' | 'A' => 0x00,
            'b' | 'B' => 0x0B,
            'c' | 'C' => 0x08,
            // ... 省略: 設計書にある通りのマップ ...
            ' ' => 0x31,
            '\n' | '\r' => 0x24,
            _ => return Err(format!("Unsupported char: {}", ch)),
        };
        Ok(code as CGKeyCode)
    }
}

## ポップアップ UI（src/ui/popup.rs）

```rust
use objc2::{class, msg_send, sel, sel_impl};
use objc2::rc::{Id, Shared};
use objc2::runtime::Object;
use objc2_foundation::{NSString, NSRect, NSPoint, NSSize};
use objc2_app_kit::{NSWindow, NSTextView};
use tokio::sync::{mpsc, oneshot};
use std::sync::Arc;
use parking_lot::Mutex;

pub struct PopupWindow {
    tx: mpsc::UnboundedSender<UiCommand>,
}

enum UiCommand {
    AppendText(String),
    GetText(oneshot::Sender<String>),
    Close,
}

impl PopupWindow {
    pub async fn create_near_cursor() -> Result<Self, String> {
        let (tx, rx) = mpsc::unbounded_channel();
        tokio::task::spawn_blocking(move || {
            Self::ui_thread(rx);
        });
        Ok(PopupWindow { tx })
    }

    fn ui_thread(mut rx: mpsc::UnboundedReceiver<UiCommand>) {
        unsafe {
            // NSWindow/NSTextView の生成（メインスレッド想定）
            let window_class = class!(NSWindow);
            let window_obj: *mut Object = msg_send![window_class, alloc];
            let frame = NSRect::new(NSPoint::new(200.0, 200.0), NSSize::new(300.0, 100.0));
            let window_obj: *mut Object =
                msg_send![window_obj, initWithContentRect:frame
                                         styleMask:15
                                         backing:2
                                         defer:false];
            if window_obj.is_null() {
                return;
            }
            let window: Id<NSWindow, Shared> =
                Id::retain(window_obj).expect("Failed to retain window");

            let tv_class = class!(NSTextView);
            let tv_obj: *mut Object = msg_send![tv_class, alloc];
            let tv_obj: *mut Object = msg_send![tv_obj, initWithFrame:frame];
            let textview: Id<NSTextView, Shared> =
                Id::retain(tv_obj).expect("Failed to retain textview");

            let content_view: *mut Object = msg_send![&*window, contentView];
            let _: () = msg_send![content_view, addSubview: &*textview];
            let _: () = msg_send![&*window, makeKeyAndOrderFront: std::ptr::null_mut()];

            let window = Arc::new(Mutex::new(Some(window)));
            let textview = Arc::new(Mutex::new(Some(textview)));

            while let Some(cmd) = rx.blocking_recv() {
                match cmd {
                    UiCommand::AppendText(s) => {
                        if let Some(tv) = textview.lock().as_ref() {
                            let ns = NSString::from_str(&s);
                            let _: () = msg_send![&**tv, insertText: &*ns];
                        }
                    }
                    UiCommand::GetText(ch) => {
                        let mut result = String::new();
                        if let Some(tv) = textview.lock().as_ref() {
                            let string_obj: *mut Object = msg_send![&**tv, string];
                            if !string_obj.is_null() {
                                let utf8: *const u8 = msg_send![string_obj, UTF8String];
                                if !utf8.is_null() {
                                    let cstr = std::ffi::CStr::from_ptr(utf8 as *const i8);
                                    result = cstr.to_string_lossy().to_string();
                                }
                            }
                        }
                        let _ = ch.send(result);
                    }
                    UiCommand::Close => {
                        if let Some(w) = window.lock().take() {
                            let _: () = msg_send![&*w, close];
                        }
                        break;
                    }
                }
            }
        }
    }

    pub async fn append_text(&self, s: &str) {
        let _ = self.tx.send(UiCommand::AppendText(s.to_string()));
    }

    pub async fn get_text(&self) -> String {
        let (tx, rx) = oneshot::channel();
        let _ = self.tx.send(UiCommand::GetText(tx));
        rx.await.unwrap_or_default()
    }

    pub async fn close(&self) {
        let _ = self.tx.send(UiCommand::Close);
    }
}
```

## メインループ（src/main.rs の最小構成）

```rust
mod config;
mod hotkey;
mod stt;
mod ui;
mod input;

use clap::Parser;
use std::path::PathBuf;
use tokio::sync::mpsc;
use hotkey::{HotkeyListener, HotkeyAction};

    Recording,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    env_logger::init();

    // 1. Accessibility 権限チェック（なければ即終了）
    KeyboardInjector::check_accessibility_permission()?;

    // 2. 設定読み込み（省略: config.rs そのまま使う）

    // 3. ホットキー開始
    let hotkey_conf = /* config.hotkeys */ todo!();
    let prompts = vec![];
    let mut hotkey_listener = HotkeyListener::new(hotkey_conf, prompts);
    let mut hotkey_rx = hotkey_listener.start();

    // 4. STT 初期化
    let mut stt = SpeechRecognizer::new("ja_JP")?;

    let mut state = AppState::Idle;
    let mut popup: Option<PopupWindow> = None;
    let mut stt_rx: Option<mpsc::Receiver<SttEvent>> = None;

    loop {
        tokio::select! {
            Some(action) = hotkey_rx.recv() => {
                match action {
                    HotkeyAction::Start => {
                        if state == AppState::Idle {
                            if let Ok(rx) = stt.start().await {
                                stt_rx = Some(rx);
                                popup = PopupWindow::create_near_cursor().await.ok();
                                state = AppState::Recording;
                            }
                        }
                    }
                    HotkeyAction::Commit => {
                        if state == AppState::Recording {
                            if let Some(p) = &popup {
                                let text = p.get_text().await;
                                KeyboardInjector::type_text(&text).await?;
                            }
                            stt.stop();
                            if let Some(p) = popup.take() {
                                p.close().await;
                            }
                            stt_rx = None;
                            state = AppState::Idle;
                        }
                    }
                    _ => {}
                }
            }
            Some(evt) = async {
                if let Some(rx) = &mut stt_rx {
                    rx.recv().await
                } else {
                    None
                }
            } => {
                if state == AppState::Recording {
                    match evt {
                        SttEvent::PartialResult(t) |
                        SttEvent::FinalResult(t) => {
                            if let Some(p) = &popup {
                                p.append_text(&t).await;
                            }
                        }
                        SttEvent::Error(e) => {
                            eprintln!("STT error: {}", e);
                            stt.stop();
                            if let Some(p) = popup.take() {
                                p.close().await;
                            }
                            stt_rx = None;
                            state = AppState::Idle;
                        }
                    }
                }
            }
        }
    }
}
